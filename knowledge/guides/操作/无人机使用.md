# 无人机使用

> 本文只回答无人机投给谁：产物之间的取向、贸易站之间的优先级与常见误区。协助耗时与持有上限等机制见 `base/设施/机制-发电站.md`，解锁条件见 `base/设施/机制-控制中枢.md`。

## 投向原则：按需与补短板

在作战记录、赤金与龙门币之间分配无人机受个人目标影响，没有唯一答案，通常按两条原则：缺什么补什么；哪条产线相对产出不足就加速哪条。

- 长期使用单一布局、钱书需求明确时，优先用无人机配平赤金供需与钱书平衡：赤金不够补赤金，钱书缺口补短板。
- 允许切换布局时，加速当前总体存在劣势的产物，补齐产出结构的短板。

## 加速效果与站内干员效率无关

无人机协助每架固定推进制造站或贸易站的基础耗时 3 分钟（见 `base/设施/机制-发电站.md`「无人机上限溢出、工作状态与协助耗时」）。同配方、同订单结构下，同样架数带来的额外产出不因干员的生产力或订单获取效率不同而变化。改变配方、站级或特殊订单结构时，基准产出可能不同，不能据此认为赤金、作战记录和龙门币的收益相同。

480 架合计推进 24 小时基础进度，因此额外产出＝投入架数÷480×该产线 1.0 效率的日基准。例如分别全投普通产线，480 架对应 20 枚赤金、8000 点作战记录经验，或三级贸易站约 10265 龙门币订单；贸易订单还需赤金交付。这是产量换算，自然充能仍按无加成时 6 分钟/架计算。

## 加速贸易站的优先级

但书、龙舌兰、可露希尔改变订单结构，同样架数的收益需按相应基准计算。以下比较长期赤金供需平衡的稳态：合计 480 架分给贸易站与赤金制造，全部订单能及时交付，赤金线基准为 10000 价值/日。

T 为该贸易配置在 1.0 效率、24 小时下的订单龙门币产值；G 为额外报酬等效的赤金价值，不是实物赤金，实际需补的赤金价值为 T−G。贸易侧分配比例为 10000÷(10000＋T−G)，最终龙门币＝10000×T÷(10000＋T−G)。按固定来源的基准与订单规则核算：

| 贸易配置 | T | G | 480 架连同补金的龙门币约值 |
|---|---:|---:|---:|
| 一级·精二但书 | 20000 | 0 | 6667 |
| 二级·精二但书 | 18591.55 | 0 | 6502 |
| 三级·精二但书＋精二龙舌兰，普通订单分布 | 16637.17 | 707.96 | 6416 |
| 三级·精二巫恋＋精二龙舌兰＋暖机裁缝 β | 12739.73 | 2328.77 | 6242 |
| 三级·精二但书，普通订单分布 | 15929.20 | 0 | 6143 |
| 任意等级·精二可露希尔 | 12000 | 2000 | 6000 |
| 普通三级贸易站 | 10265.49 | 0 | 5066 |

但书与龙舌兰同站这一档按二、三、四赤金订单 30%/50%/20% 计算。两人须在新订单开始获取前到位，分别改造二、三赤金档和四赤金档；订单确定后可换回加速队友，再计时或使用无人机，交付时无需重新放入。若巫恋常驻且裁缝 α 暖机完成，按观测分布 15%/30%/55% 估算，应改用该配置的基准，不能套普通分布档。

第四档按巫恋自身裁缝 α 与第三人的裁缝 β 共同暖机后的 5%/10%/85% 观测分布计算。裁缝 β 等价技能可由柏喙、明椒、折光或卡夫卡精二提供，约需连续在岗 5 小时；巫恋的 α 约需 3 小时。精零龙舌兰、未暖机或其他裁缝配置不套该行。第 4、5 行虽是但书的订单产值更高，但它需要补更多赤金；龙舌兰的额外报酬不增加耗金，配平后反超。具体技能与组站条件见 `guides/组合/贸易站组合.md`。

## 长期配平与单次库存的区别

长期赤金平衡的优先级已把补赤金的成本摊入各项，在同一稳态口径下不因某次库存高低改变。若只比较这一次加速、现有赤金足够且本次不补金，则应直接比较 1.0 效率日订单产值 T：三级精二但书的 15929.20 高于精二巫恋＋精二龙舌兰＋暖机裁缝 β 的 12739.73，不能把长期顺序直接套到这次操作。

不同产物之间的选择还取决于基建外收入、是否切换布局与当期目标；先确定要补的缺口，再在对应产线内比较。
