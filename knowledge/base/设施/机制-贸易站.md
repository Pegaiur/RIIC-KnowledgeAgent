# 贸易站机制

> 来源：罗德岛基建/贸易站（PRTS，抓取于 2026-09-03）；订单释义补充自 arknights-base-vault，采用版本与判断见 docs/archive/plan-knowledge-correctness.md 实施纪要。具体技能效果、持有者、解锁与替换以 facts 返回的记录为准。

本篇区分订单获取效率、处理时间与订单上限，分别说明订单确定时点、普通与特殊订单的属性，以及进驻和设施等级的影响。

## 订单获取效率、处理时间与订单上限

订单上限、订单获取效率和订单处理时间是三个不同指标：

- 订单上限决定贸易站可以同时保留多少笔订单；
- 订单获取效率影响获取订单的计时；
- 订单处理时间由订单类型和对应规则决定，不能把订单上限直接当作处理速度。

普通订单的订单获取效率可按 `100% + X + Y` 理解：基础值为 100%，每名处于工作状态的干员提供 `+1%` 的进驻加成，`Y` 为后勤技能额外提供的订单获取效率。订单上限另行结算，只有技能文本明确读取订单上限时，才把上限变化带入该技能的计算。

## 贸易站进驻人数与心情消耗

贸易站的心情消耗按 `1 + X + Y` 展示：1/2/3 名处于工作状态的干员对应人数项为 0/-0.05/-0.1，`Y` 为后勤技能与控制中枢提供的群体心情消耗效果之和。计量表不一定包含干员自身技能造成的变化。

## 订单确定时点与谈判策略生效范围

订单在获取计时开始时确定。修改谈判策略不会改写已经生成的当前订单，而是在当前订单生成后的下一次获取开始时生效。

但书、龙舌兰等订单改造也在新订单开始获取时判定。干员中途进驻不会追溯改造当前订单；改造完成后撤出干员，已经确定的交付数与报酬保留，后续计时按当时在站的订单获取效率推进。

## 普通订单的交付数量、报酬与获取时间

龙门商法的基础订单为：2/3/4 份赤金分别换取 1000/1500/2000 龙门币，基础获取时间分别为 2:24:00、3:30:00、4:36:00。三级贸易站可使用开采协力：2 份源石碎片换取 20 合成玉，基础获取时间为 2:00:00。

## 赤金订单概率与高品质订单条件

三级贸易站贵金属订单中，需求为 2/3/4 份赤金的基础概率为 30%/50%/20%；二级为 60%/40%/—，一级为 100%/—/—。裁缝类技能改变高品质订单的出现概率，不直接增加订单获取效率；巫恋「低语」归零同站其他干员的订单获取效率时，裁缝的概率效果仍可生效。

裁缝类需要连续在岗暖机：α 约 3 小时、β 约 5 小时达到峰值，换工位或离站重进会重新累积。三级站的观测中，单 α、双 α、α＋β 的四赤金订单占比分别约为 55%、65%、85%。这些是指定配置的观测值，暖机曲线与多人组合没有统一计算公式。长班较易保留峰值，短班换人需计入重新暖机的影响。

四赤金订单增多有利于龙舌兰「投资」，却会减少但书「合同法」的触发机会。可露希尔的特别订单和佩佩的特别独占订单固定类型，裁缝没有概率可改；U-Official 的尤里卡订单仍继承抽中档位的耗时，提高品质只会延长平均等待，不提高单笔报酬。

## 特殊订单的耗时、报酬与属性继承

一份订单只改变为一种特殊订单。单笔报酬与订单获取效率分开计算：前者决定每笔能换多少龙门币，后者通常缩短获取计时；提高效率不会把单笔报酬再次乘大。

按当前来源的优先级，5 类特殊订单为：特别独占订单（高）、特别订单（较高）、尤里卡订单（中）、违约订单（较低）、龙舌兰订单（低）。这里列的是订单类型，不是触发技能或持有者清单。

| 订单类型与触发者 | 订单属性与条件 |
|---|---|
| 特别独占订单：佩佩精二 | 固定用时 4:30:00、交付 0 份赤金、报酬 1000 龙门币；不受订单获取效率影响，可用无人机推进 |
| 特别订单：可露希尔精二 | 基础用时 2:24:00、交付 2 份赤金、报酬 1200 龙门币；自身及队友的订单获取效率照常缩短计时 |
| 尤里卡订单：U-Official 精零 | 固定交付 2 份赤金、报酬 1000 龙门币；耗时继承原订单抽中的 2/3/4 赤金档，仍受订单获取效率影响 |
| 违约订单：但书 | 原交付数小于 4 时，精零 α 档交付数 +1、报酬 +500 龙门币；精二 β 档交付数 +2、报酬 +1000 龙门币；耗时不变 |
| 龙舌兰订单：龙舌兰 | 原交付数大于 3 时，精零 α 档报酬 +250 龙门币；精二 β 档报酬 +500 龙门币；仍交付 4 份赤金，耗时不变 |

但书与龙舌兰分别处理原本的二、三赤金订单和四赤金订单，可以同站；违约订单不会再触发投资。佩佩、可露希尔、U-Official 的订单覆盖两者的改造，适合分站安排。可露希尔每笔多得的 200 龙门币、龙舌兰追加的报酬都不增加赤金消耗，也不产生实物赤金；但书则同时增加赤金消耗与龙门币报酬。
