## 办公室 机制公式
> 来源：罗德岛基建/办公室（PRTS，抓取于 2026-09-03）

### 公式与规则
| 条款 | 数值/规则 | 来源小节 |
|---|---|---|
| 基础刷新时长 | 「增加1次的基础时长为12小时」（联络进度亦注「获取1次联络次数需要12小时」） | 概述·联络人脉 / 效用数据 |
| 联络速度 +5% | 「办公室进驻非注意力涣散的干员时，人脉资源的联络速度**+5%**」（效用数据同为联络速度 +5%） | 概述·联络人脉 / 效用数据 |
| 刷新次数恢复条件 | 人脉资源（刷新次数）初始为 **0**；未进驻干员时**不会恢复**；进驻后开始恢复 | 概述·联络人脉 |
| 人力资源余量 | 默认 **0/3**（联络次数/公开招募标签刷新次数）；达到上限时进驻干员将**暂停工作** | 效用数据 |
| 公招功能完整性 | 公开招募基础功能不需要建造办公室，但办公室状态影响功能完整性 | 公开招募 |
| 龙门币优惠删除 | 2024-05-15 更新后公开招募不再消耗龙门币，龙门币优惠同时删除 | 概述 / 建造与升级 |
| 扩展招募位 | 办公室扩展公开招募可提供的招募位（Lv1/2/3 = 2/3/4） | 概述 / 建 造与升级 |
> 技能维度数值：「法为正典」+50% 联络速度、斥罪 19.2h 不适用 24h 班、凯尔希·思衡托需 5 处设施精英（泰拉的方舟 +30%/每间 +4%）等以 references 为准，不在本爬 取范围（🟡 待重算）。
