## 控制中枢 机制公式
> 来源：罗德岛基建/控制中枢（PRTS，抓取于 2026-09-03）

### 公式与规则
| 条款 | 数值/规则 | 来源小节 |
|---|---|---|
| 全局心情消耗减免 | 计量表默认 1 `-X`（工作区自身）与「全员心情消耗/时」默认 0 `-X`；X=每名处于工作状态的干员提供 **−0.05**（即 0.05 的心情消耗减免） | 效用数据 |
| 「全员心情消耗/时」口径 | 该值反映「全员心情消耗**减免值**」而非文本字面「全员心情消耗/时」；代表所有工作区设施（**不含控制中枢、加工站等瞬间结算类设施**）内进驻干员的额外心情消耗情况 | 效用数据 |
| 计量表不含技能 | 上述计量表**不计入后勤技能效果**，实际各设施心情消耗可能有差异 | 效用数据 |
| 电力恒 0 | 所有等级**电力消耗 0**（提供 0 电力） | 建造与升级 |
| 不可降级 | 控制中枢 **不可降级** | 建造与升级 |
| 副手不算进驻 | 「任命副手并不视为进驻基建。」被任命为基建副手者始终出现在基建设施中（默认在其对应控制中枢/所在楼层宿舍），但**不计进驻** | 概述·基建副手 |
| 副手位解锁 | 基建副手位随楼层开放（基于控制中枢等级）逐个解锁：Lv1 控制中枢、B1；Lv3 +B2；Lv4 +B3；Lv5 +B4 | 概述·基建副手 / 建造与升级 |
| 副手简报时段 | 每日记录时段为当日 **4:00 至次日 3:59**；记录近 3 日制造站/贸易站/宿舍与本副手信赖 | 概述·基建副手 |
| 无人机协助 | 控制中枢 Lv.3 解锁（制造站/贸易站）：消耗无人机加速制造与订单获取 | 建造与升级 |
| 急速充能 | 控制中枢 Lv.4 及以上解锁；**每 1 理智立刻获得 2 架**无人机；可充能数目受无人机上限影响，**持有数 ≥ 上限−1 时无法急速充能** | 概述·无人机急速充能 |
| 5 席竞争 | 进驻人员上限逐级 +1：Lv1=1 … Lv5=**5**（总等级数=5） | 建造与升级 |
| 基建设施等级上限 | 控制中枢等级上限控制部分设施最高等级：Lv1=1 … Lv5=5 | 建造与升级 |
> 技能维度数值（全局光环同种取最高、派系计数、歌蕾蒂娅 3.2/h/短班 7.5h 等）以 references 为准，不在本爬取范围。

### 等级范围与相关参数（升级表仅取所需，素材/升级条件已剔除）
| 等级 | 进驻人员上限 | 基建设施等级上限 | 电力消耗 | 解锁/副手位 |
|---|---|---|---|---|
| 1 | 1 | 1 | 0 | 副手位：控制中枢、B1 |
| 2 | 2 | 2 | 0 | — |
| 3 | 3 | 3 | 0 | 副手位 +B2；制造站/贸易站解锁【无人机协助】 |
| 4 | 4 | 4 | 0 | 副手位 +B3；基建解锁【急速充能】 |
| 5 | 5 | 5 | 0 | 副手位 +B4 |
> 注：升级条件（前置设施：5×Lv.1 / 6×Lv.1 / 8×Lv.2 / 10×Lv.3 设施）与素材（无人机/建材）已按规范剔除。
