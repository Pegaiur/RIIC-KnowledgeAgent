# 贸易站机制

> 来源：罗德岛基建/贸易站（PRTS，抓取于 2026-09-03）。具体技能效果、持有者、解锁与替换以 facts 返回的记录为准。

本篇按订单获取与处理、策略生效时点、订单分布和设施等级展开；涉及完整订单流程时，结合这些小节阅读。

## 订单上限与订单获取效率

订单上限、订单获取效率和订单处理时间是三个不同指标：

- 订单上限决定贸易站可以同时保留多少笔订单；
- 订单获取效率影响获取订单的计时；
- 订单处理时间由订单类型和对应规则决定，不能把订单上限直接当作处理速度。

普通订单的订单获取效率可按 `100% + X + Y` 理解：基础值为 100%，每名处于工作状态的干员提供 `+1%` 的进驻加成，`Y` 为后勤技能额外提供的订单获取效率。订单上限另行结算，只有技能文本明确读取订单上限时，才把上限变化带入该技能的计算。

贸易站的心情消耗按 `1 + X + Y` 展示：1/2/3 名处于工作状态的干员对应人数项为 0/-0.05/-0.1，`Y` 为后勤技能与控制中枢提供的群体心情消耗效果之和。计量表不一定包含干员自身技能造成的变化。

## 订单策略与确定时点

订单在获取计时开始时确定。修改谈判策略不会改写已经生成的当前订单，而是在当前订单生成后的下一次获取开始时生效。

龙门商法的基础订单为：2/3/4 份赤金分别换取 1000/1500/2000 龙门币，基础获取时间分别为 2:24:00、3:30:00、4:36:00。三级贸易站可使用开采协力：2 份源石碎片换取 20 合成玉，基础获取时间为 2:00:00。

## 贵金属订单分布

三级贸易站贵金属订单中，需求为 2/3/4 份赤金的基础概率为 30%/50%/20%；二级为 60%/40%/—，一级为 100%/—/—。高品质贵金属订单的 α/β 分布和达到条件由贸易站技能原文决定，具体技能以 facts 返回的记录为准。

已有观测到 αα、αβ 等多技能组合的分布变化，但来源没有给出可泛化的统一叠加公式；这些观测不能替代具体技能文本，也不作为本篇的确定性计算规则。

## 特殊订单

当前来源列出 5 类特殊订单；一份订单只改变一种特殊订单类型。特殊订单有各自的优先级、交付数量、报酬或固定时长规则，不能把它们统一折算为普通订单获取效率。

按当前来源的优先级，5 类特殊订单为：特别独占订单（高）、特别订单（较高）、尤里卡订单（中）、违约订单（较低）、龙舌兰订单（低）。这里列的是订单类型，不是触发技能或持有者清单。

| 订单类型 | 已确认的订单属性 |
|---|---|
| 特别独占订单 | 固定用时 4:30:00、交付 0 份赤金、报酬 1000 龙门币；不受订单获取效率影响 |
| 特别订单 | 固定用时 2:24:00、交付 2 份赤金、报酬 1200 龙门币 |
| 尤里卡订单 | 交付 2 份赤金、报酬 1000 龙门币，其余属性继承原订单 |
| 违约订单 | α 档交付数 +1、报酬 +500 龙门币；β 档交付数 +2、报酬 +1000 龙门币；其余属性继承原订单 |
| 龙舌兰订单 | α 档报酬 +250 龙门币；β 档报酬 +500 龙门币；其余属性继承原订单 |

α/β 只表示来源表中的订单属性档位；具体技能、持有者和触发条件仍以 facts 返回的记录为准。
