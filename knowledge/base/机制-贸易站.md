## 贸易站 机制公式
> 来源：罗德岛基建/贸易站（PRTS，抓取于 2026-09-03）

### 公式与规则
| 条款 | 数值/规则 | 来源小节 |
|---|---|---|
| 订单上限 Lv1-3 | 订单上限 **6 / 8 / 10** | 建造与升级 |
| 获取订单效率 | 默认 `+X% +Y%`；X=基础效率加成，每名处于工作状态的干员 +1%；Y=干员后勤技能额外效率加成 | 效用数据·获取订单效率 |
| 效率组成 | 基础效率 **100%** + 进驻加成 **每名工作干员 1%** + 后勤加成（技能总和） | 效率组成 |
| 心情消耗公式 | 默认 `1 +X +Y`；X=基础心情消耗，按处于工作状态干员数：1 名无消耗（不显示）、2 名 −0.05、3 名 −0.1；Y=后勤技能与控制中枢群体心情消耗之和 | 效用数据·心情消耗 |
| 订单在获取计时时确定 | 「订单在获取计时时即确定」；修改谈判策略后，当前订单生成后的**下一次获取开始时**才生效新策略 | 谈判策略与订单 |
| 龙门商法（贵金属订单） | 赤金 2/3/4 → 龙门币 1000/1500/2000；基础获取 2:24:00 / 3:30:00 / 4:36:00 | 谈判策略与订单 |
| 开采协力（源石订单） | Lv.3；源石碎片 2 → 合成玉 20；基础获取 2:00:00 | 谈判策略与订单 |
| 贵金属生成概率 | 「贵金属订单的生成概率」：订单需求 赤金2/3/4 在 Lv1 为 100%/−/−、Lv2 60%/40%/−、Lv3 **30%/50%/20%** | 贵金属订单的生成概率 |
| 裁缝 α/β 分布 | 「受技能影响」表（均为 Lv3 结果）：常规 30/50/20；α级 **15/30/55**（期望 3.4）；β级 **5/10/85**（期望 3.8） | 贵金属订单生成概率分布受技能的影响 |
| α 级达成条件 | α 级需进驻贸易站**累积工作 3 小时**后达到该值；β 级需**累积 5 小时**；离开/工位改变时累积清零 | 同上 |
| αα / αβ 叠加（观测） | αα 叠加观测 65%/22%/13%（期望 3.46）；αβ 叠加观测 85%/10%/5%（期望 3.8）；**「具体叠加模型暂不确定」** | 同上 |
| 特殊订单 5 种 | 截止「相变临界」(2026/5/1) 共 5 种，一份订单仅可变一种 | 特殊订单 |
| 特殊订单优先级 | 佩佩（高）> 可露希尔（较高）> 尤里卡（中）> 但书（较低）> 龙舌兰（低） | 特殊订单 |
| 佩佩固定时长 | 订单时长 4:30:00 **（不受订单获取效率影响，固定用时）**，赤金 0、报酬 1000 | 特殊订单 |
| 但书违约索赔 | α：赤金交付 +1、报酬 +500；β：赤金交付 +2、报酬 +1000 | 特殊订单 |
| 龙舌兰投资 | α：报酬 +250；β：报酬 +500 | 特殊订单 |
| 倒计时 | 干员信息「倒计时」=以当前剩余心情与消耗速度进入**注意力涣散**的理论时间（未纳入消耗速度变动，可能不实） | 其他信息 |
> 技能维度数值（技能加上限：喀兰之主、喀兰贸易 α/β、半身人公会代表/大巴扎管理学/使命必达/少当家、供应管理；孑市井之道等）以 references 为准，不在本爬取范围。
