## 制造站 机制公式
> 来源：罗德岛基建/制造站（PRTS，抓取于 2026-09-03）

### 公式与规则
| 条款 | 数值/规则 | 来源小节 |
|---|---|---|
| 生产力面板 1+X+Y | 默认 `1 +X +Y`；X=基础生产力加成，**每进驻 1 名非注意力涣散的干员获得 +1%**；Y=干员后勤技能额外提供的生产力加成 | 效用数据·生产力 |
| 仓库容量 | 每个制造站仓库体积容量独立计算，非实际道具仓库（暂存仓库）；「仓库容量（X/Y）」为容积状态 | 概述·产品体积 / 效用数据 |
| 未收取不入库 | 未收取的产品不会进入道具仓库（不视为持有） | 概述·操作流程 |
| 心情消耗公式 | 默认 `1 -X -Y`；X=基础心情消耗减免，按进驻人数：1 名无减免（不显示）、2 名 0.05、3 名 0.1；Y=干员后勤技能与控制中枢额外提供的心情减免之和 | 效用数据·心情消耗 |
| 计量表不含自身 | 此处计量表不计入自身心情消耗的影响，实际心情消耗可能有差异 | 效用数据·心情消耗 |
| 已节省 | 相对通常生产力的累计节省时间；可为负但显示不低于 0；重设制造方案重置计时器 | 效用数据·已节省 |
| 制造启动条件 | 指定制造方案 + 份数 + 进驻干员后才开始制造；记录时间为**无加成下的基础时间** | 制造方案 |
| 方案解锁 | 部分方案需设施升级解锁（表中「制造站等级」=曾达到即解锁），已解锁配方任意等级可用 | 制造方案 |
| 原料预扣 | 含原料方案选定即预扣原材料（立即扣除所需数）；单个产品完成前原料不视为消耗；下调方案数归还材料 | 制造方案 |
| 自动补货 | 自「黄铁行动」起新增；开启后对无原料消耗方案，每次收取自动将方案数量设到最大值 | 制造方案 |
| 双芯片用时 | 自「相见欢」起，所有双芯片制造方案单份用时从 1 小时缩短至 **1 秒** | 制造方案·芯片 |
> 技能维度数值（技能类型学 cc.sk.manu1/2/3/4、意识协议/源石技艺理论应用/打工心得 +5%、槐琥团队精神消除、归零系列等）以 references 为准，不在本爬取范围。
