## 活动室使用、进驻与信赖入口

活动室安排干员“使用”，不占生产设施或宿舍的进驻席位，干员可以同时在其他设施正常工作。活动室不耗电，也不消耗或恢复心情；氛围值增加的是每日活动信赖获得量，不能替代宿舍恢复。

只安排活动室使用或副手任命，不满足技能所要求的“进驻基建内”人数条件；同一干员另有实际进驻时，按真实设施与技能条件计数。活动室里的显示位置不能代替制造站、贸易站等挂件岗位。

基建副手每日有两次信赖收取机会，入口在控制中枢；活动室另提供每日额外信赖机会。两者增加的是同一项干员信赖，安排信赖用途时无需撤下其实际工作岗位。副手位与楼层的关系见机制-控制中枢.md。

## 进驻标识、工作状态与注意力涣散

| 条款 | 数值/规则 | 来源小节 |
|---|---|---|
| 进驻心情上限 | 每名干员拥有最高 **24 点**心情 | 进驻状态·标识状态 |
| 进驻标识：未进驻 | 未进驻任何设施，心情不变，无任何标识 | 进驻状态·标识状态 |
| 进驻标识：已进驻 | 进驻任意设施，标舱室位置编号与设施类型；按心情消耗速率分「工作中/空闲中/休息中」三态 | 进驻状态·标识状态 |
| 工作状态定义 | 进驻于**正在工作的工作区设施**即视为「工作状态」——与标识无关，即使标识为「空闲中/休息中」也算工作状态；**注意力涣散干员不算工作状态** | 工作状态 |
| 注意力涣散 | 心情为 0（无论进驻与否）；其后勤技能与基础效率在内的大部分加成失效 | 进驻状态·标识状态 |
| 宿舍锁定/训练中标识 | 宿舍锁定位置→「锁定中」；训练位且正专精→「训练中」（仅队列编辑可见） | 进驻状态·标识状态 |

## 进驻工位匹配、换位与暖机重置

| 条款 | 数值/规则 | 来源小节 |
|---|---|---|
| 座椅（工位）制 | 进驻按「座位制」，系统将新队列与现有队列**一一匹配**；同一干员仅当**位置相同**才视为保留，否则视为重新进驻（卸下原干员+进驻新干员） | 进驻机制 |
| 暖机重置 | 需一定时间达到封顶值（暖机）的技能在**换位时被重置**（因重新进驻） | 进驻机制·衍生情况 |

## 预设队列轮换、干员休整与宿舍锁定

| 条款 | 数值/规则 | 来源小节 |
|---|---|---|
| 批量编辑（队列轮换） | 自「揭幕者们」（2024/11/1）起，工作区（控制中枢/产出设施/会客室/办公室）可设最多 **3 个预设队列**批量切换；快速切换按「所有干员均未处于训练室训练位（无论是否正在专精）＞总心情比例最高＞队列序号靠前」选队列 | 进驻方法·批量编辑 |
| 队列轮换的适用范围 | 预设队列只提供给工作区的控制中枢、产出设施、会客室与办公室；训练室与加工站不提供预设队列，其中的干员不适用队列轮换，也无法通过一键休整换下 | 进驻方法·批量编辑 |
| 预设队列的生成与标记 | 新增预设工作队列时，若该设施所有干员均不在任一队列中，则按当前已进驻干员生成，否则创建空队列；处于任一队列中的干员在干员配置界面右上角显示蓝色标记 | 进驻方法·批量编辑 |
| 队列切换的限制 | 干员位于训练位或注意力涣散时，无法通过快速切换应用其所在队列；无法应用空队列；无法应用有干员正在训练室训练的队列；当前工作干员与所选队列干员相同（即使位置不同）视为该队列应用中，无法切换 | 进驻方法·批量编辑 |
| 全局批量应用 | 代办事项或进驻总览中的「队列轮换」对存在未进驻干员或注意力涣散干员的工作区设施各执行一次快速切换 | 进驻方法·批量编辑 |
| 干员休整 | 宿舍按「未进驻且心情未满」由心情低至高进驻空闲位；优先氛围高＞楼层靠上＞位置靠前；自「相见欢」起，仅当所安排位置中存在其他干员时才移出该干员，心情已满的干员不被强制移出 | 进驻方法·批量编辑 |
| 锁定编辑 | 自「相见欢」（2025/1/22）起宿舍支持锁定编辑；宿舍分锁定区域与非锁定区域，干员休整仅在非锁定位置进行，锁定但空置的位置同样保持空置；手动编辑单个宿舍时同时只能编辑其中一个区域，进驻上限受该区域位置数限制；锁定区域干员显示「锁定中」，进驻其他类型设施（活动室除外）需二次确认；锁定编辑不影响后勤技能生效 | 进驻方法·批量编辑 |
| 预设队列与锁定区互斥 | 同一干员不能同时存在于宿舍锁定区和预设队列；把预设队列中的干员锁进宿舍时会先将其从工作队列撤下并二次确认 | 进驻方法·批量编辑 |
