# facts-first 质量闭环与后续迭代草案

> 创建日期：2026-09-04
> 状态：草案（draft）
> 上游：`docs/archive/plan-hybrid-facts.md`（facts-first 基础设施已收口）

## 目标

在确定性记录卡与查询工具基础上，后续逐步补齐事实表达质量、语义抽检和可复核的答案评测；本草案不作为当前基础设施合并的前置条件。

## 非目标

- 不回滚或扩大当前已合并的 facts-first 运行时边界。
- 不把 dry run、工具链路测试或单次真实冒烟误当作答案质量结论。
- 不在没有明确真源和判定口径前批量填充人工优化内容。

## 架构分析

当前记录卡的机械字段、技能事实、持有关系、类别与等价组已经由 `knowledge/references/` 确定性解析并通过全量门禁；人工 curation 批次仍为空，`docs/spec/rag-answer-baseline.md` 也仍是旧散文语料背景下的 v2 基线。后续工作需要先重建判定口径，再把语义修订和真实答案评测分开留痕，避免用工具覆盖率替代答案质量。

## 实施方案

1. **P0.4 参考要点重制**：以当前可核验的 `knowledge/references/` 与机制真源为依据，重制 F01-F10/G01-G02 的参考要点和陷阱点；明确每条要点的来源边界，更新 spec 版本并人工终审。
2. **语义字段抽检**：按设施和字段类型抽取代表性记录，核对原文效果、代偿备注和相关组合；必要时写入对应 curation 模块，保留原文指纹和修订理由。
3. **查询/裸查对照**：定义 12 个事实题加 5 个组合题的固定题集，使用同模型、同参数分别运行查询组与无工具裸查组；运行结果、失败项和成本信息落盘。
4. **人工判定与结论**：按重制后的 spec 逐题核查答案，落盘判定表；分别报告工具命中、答案覆盖、编造、成本和已知局限，不把结论外推到未测 provider。
5. **v3 规划**：根据核查结论登记 S 类、散文重写、`minEff` 数值效率和 references 再生脚本等后续工作；范围稳定后将本草案转为正式 plan。

## 验收清单

- [ ] F/G 参考要点已按当前真源重制，spec 已递进版本并完成人工终审
- [ ] 语义字段抽检完成，必要的 curation 覆盖已写入并通过指纹校验
- [ ] 12+5 题查询/裸查两组运行完成，结果与成本信息已落盘
- [ ] 答案人工判定表已落盘，判定口径和异常项可复核
- [ ] 结论与局限已记录，v3 后续工作已登记
