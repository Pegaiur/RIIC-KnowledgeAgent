# RAG 散文统一术语

> 本规则只约束人工清洗的玩家侧散文（`knowledge/base/`、`knowledge/guides/`）。`knowledge/raw/` 是版本控制内的机械事实真源，保留其字段格式与原始措辞；代码字段名、历史归档和引用旧称不据此批量改写。

新增、导入、改写或审阅上述人工散文前，必须同时读取并遵循 docs/spec/rag-prose-writing.md。本文件唯一维护规范词与练度写法，正文组织、表达要求和写作示例由该 spec 维护；类别.md、歧义.md 的直出层例外见下文。

## 使用原则

1. 正文首次出现概念时使用下表规范词；标题、表头、成员练度和结论句同样适用。
2. 旧称仅在解释检索别名时出现一次，并明确标成“旧称”；不得与规范词交替叙述。
3. 不把语义不同的概念强行合并。例如“精零即可”是最低练度，“不设独立培养目标”是推荐策略，二者不能互相替代。
4. 原始 UI 字段或技能原文确需逐字引用时使用引号，并在相邻正文给出规范词；当前自动检查不为引用开白名单，新增例外前应先判断能否改写。

## 规范词表

| 概念 | 规范写法 | 禁止混用 | 说明 |
|---|---|---|---|
| 干员稀有度字段 | 稀有度 | 星级 | 玩家侧表头与叙述统一称“稀有度” |
| 稀有度值 | 一星、二星、三星、四星、五星、六星 | `1星`～`6星`、`1★`～`6★`、`☆1`～`☆6` | raw 机械真源中的 `☆N` 不改 |
| 精英阶段 | 精零、精一、精二 | 精英 0/1/2、精0/1/2、E0/E1/E2 | 练度目标一律用中文简称 |
| 最低练度为未精英化 | 精零、精零即可 | 无练度要求、无额外练度要求、不要求额外培养 | 只要拥有就满足时仍明确写“精零” |
| 不产生单独培养建议 | 不设独立培养目标 | 无练度要求 | 这是推荐策略，不代表某个技能的解锁阶段 |
| 贸易站速度指标 | 订单获取效率 | 订单效率、贸易效率 | 订单上限和特殊订单不是订单获取效率 |
| 制造站速度指标 | 生产力 | 生产效率 | 与仓库容量分开计算 |
| 人力办公室速度指标 | 联络速度 | 联络效率 | 设施简称“办公室”可在上下文明确时使用 |
| 制造站容积指标 | 仓库容量 | 仓库上限、仓库容量上限 | 不与道具仓库混淆 |
| 干员工作状态值 | 心情 | 体力 | “理智”只用于玩家消耗，不属于本项 |
| 经验产物 | 作战记录 | 经验书 | “经验制造”可作为用途分类简称 |
| 可进驻的游戏单位 | 干员 | 角色、人物 | 角色名也统一称“干员名” |
| 会客室获取行为 | 线索搜集、线索搜集速度 | 线索收集、线索收集速度 | 与 raw 机械真源的“搜集”写法一致 |
| 技能解锁层次 | 技能解锁档 | 技能档 | 不等同于技能等级 |

## 练度边界

- 一星、二星干员若需要具体等级，在目标后写阿拉伯数字加空格，如“30 级”；不得写成精一。
- 组合成员只承担阵营、设施数量或持有计数，且拥有即可满足时，写“某某精零”或“成员均精零即可”。
- 挂件不应单独触发培养建议时，另写“挂件不设独立培养目标”；不得用这句话掩盖其最低练度。
- 技能需要更高阶段才能生效时，以 `knowledge/raw/技能-<设施>.md` 的解锁档为准，不从稀有度推测精一或精二。

## 自动检查

运行 `pnpm run check:prose-terms`。脚本扫描 `knowledge/base/**/*.md` 与 `knowledge/guides/**/*.md`，发现规范词表中的禁用写法即失败；该检查也是合并门禁的一部分。

例外：`knowledge/guides/类别.md` 与 `knowledge/guides/歧义.md` 是保留原格式的参考资料（术语表条目与名称对照），这两个精确路径整文件不进入禁词匹配，实现见 `scripts/prose-terms-check.mjs` 的精确路径白名单。例外只登记这两条路径，不按头注、文件名模式或整个 `knowledge/guides/` 放宽；它也不豁免来源、定位及指令冲突审阅。
