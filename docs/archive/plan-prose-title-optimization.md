# 散文标题定位与结构优化计划

> 创建日期：2026-09-13
> 状态：已完成
> 范围调整：2026-09-18 — 按用户决定，把原「语料补充与整理计划」中的「按批补充与整理语料」部分拆出为未定稿草案 docs/draft-corpus-supplement.md；本计划收缩为标题定位与结构优化（原第 5、6 节）。原计划的三批外部语料导入未在本分支实施，去向见该草案。

## 目标

以「隐藏正文后，仍能从标题树判断证据主题与阅读范围」为组织目标，审阅并重组白名单内人工散文的标题与章节结构，使目录树送达形态下模型能据此选到正确的小节入口或改用整篇入口。

## 非目标

- 不导入外部语料、不新增游戏事实与精确数值，不新增技能最低触发结论；语料按批导入归 docs/draft-corpus-supplement.md。
- 不改检索实现、topK、maxContextChars、工具契约、预算与查询 Agent 指令。
- 不定义关联格式与展开协议（归 docs/plan-prose-linked-knowledge.md）；标题迁移只同步既有定位与关联，不扩大标注范围。
- 不把标题可达性、检索成绩或模型一次选读当作回答质量改善的证据。
- 不为当前题目排名反复调整标题或扩大 topK。

## 架构分析

默认送达已是同文件目录树加命中节点预览（ADR-023）：命中节点带可调用 ID，未命中小节只呈现标题，模型的选择空间收敛为「已送达的命中节点」与「整篇入口」。因此标题是否能在脱离正文时独立识别证据主题与阅读范围，直接决定模型能否选到正确入口或判断需要改读整篇。

标题拆分与合并会改变小节 ID、检索块与定位块计数，进而影响 prose-links 登记、gold 定位与 spec 证据位置；这些定位属评测资产，必须同步迁移而不能据此重算历史成绩。标题字符总量与离线 hitrate 属观测指标，不与回答质量改善互为结论。
