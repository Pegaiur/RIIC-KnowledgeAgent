## 阻塞与解决
> 遇到的阻塞问题及解决方案

### 2026-09-03 — 批次限制失真
- **症状**：草案「一次最多取 3 页／3 个请求」与 MediaWiki `prop=revisions` 默认 ≤50 titles 不符。
- **根因**：将匿名限额/URL 长度误判为 API 硬性上限。
- **解决方案**：改为「≤4 页/批、8 页合并为 2 个批量请求」（控制体积与 URL 长度）。
- **预防**：API 能力以官方文档为准；实测确认。
