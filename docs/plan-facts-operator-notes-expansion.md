# facts 干员导航备注扩展计划（核心成员互指 + 跨组合成员）

> 创建日期：2026-09-11
> 状态：施工中
> 需求入口：docs/inbox.md「facts 干员导航备注扩展」

## 目标

在上一轮「facts 组合跨引用导航备注」（docs/plan-facts-crossref-navigation.md）基础上，把干员级备注（operator notes）扩展到下述两类成员卡，使相关核心成员具有组合导航或可继续查询的等价线索，并补齐已登记跨组合成员的多重身份：

1. **核心成员互指**：为缺少导航的核心成员卡补一条指向该组合的备注；保留已有技能点名队友或技能组导航的五个例外，不要求每张核心卡直接展示组合身份。
2. **跨组合成员**：在组合成员表中同时登记于 ≥2 个组合的干员，其单条备注需覆盖这些组合并按来源区分角色与用途。

范围固定为内容补充：不改检索、打分、分块、facts 匹配逻辑，不改变 facts_search 的命中集合与路径（备注不进入匹配索引）。

## 非目标

- 不改检索、打分、分块与 facts 匹配逻辑；不改 agent loop、工具预算与扣点规则。
- 不改题集、gold、spec、知识库 references 与 guides；不针对 benchmark 题号、问法或预期答案做特判。
- 不新增哈希/指纹字段（编码核心约束 #10）；operator notes 无 expectedHash 属既有已知债务，沿用指向式与来源标注降低漂移风险。
- 不补零命中的入口词条（喀兰贸易、人间烟火、自动化、感知信息、喀兰等），仍属词条覆盖现象。
- 不处理「combo 登记名与阵营名差一字」问题（单独决策），不为挂件/次级/可选成员逐张补备注（本轮只到核心成员与跨组合成员）。
- 不删除或改造内部遗留的 lookup / queryOperators。

## 架构分析

**notes 机制现状**（bench/src/facts/store.ts、bench/src/facts/project.ts、bench/src/facts/curation/types.ts）：

- OperatorCuration.notes 全局按 operatorId 唯一，重复登记抛错；渲染为命中卡上的「备注：…」（store.ts serializeCard），但不进入 facts_search 索引，故增删备注不改 facts_search 的命中集合与路径。
- validateCurations 对 operator 批次只校验 operatorId 存在性、重复与空文本，**不校验设施一致性**（对比 skills/grants 批次有 room 校验），批次归位属人工约定，且批次 room 不参与渲染。
- 上一轮共落位 19 条 operator notes（trade 8、control 3、manufacturing 6、dormitory 1、training 1），每组合基本只有一张承载卡携带组合导航。
- facts_search 查询精确组合名时，serializeFactsMatches 会通过 renderComboPath 输出登记的成员角色、组合条件和来源，再附成员卡；短备注可引导该查询获取完整的已登记条件，无需依赖某一张卡承载全部条件。

**离线审计证据**（dev-temp 一次性产物，未入库，收尾清理）：

- 对 19 个组合的 35 个核心成员逐个执行 facts_search(成员名)，检查返回卡备注是否含该组合名，并扫描技能文本/技能组等价线索。
- 结果：22 个核心成员缺组合名导航，分类为——真缺口 15、已有机制备注但缺组合导航 2（巫恋、孑）、已有技能文本等价线索 4（蕾缪安、德克萨斯、拉普兰德、深巡）、已有技能组导航 1（苍苔）。
- 另核查出现在 ≥2 个组合中的干员：共 6 个（能天使、令、琴柳、夕、乌尔比安、砾），其中能天使、令、乌尔比安已有单组合备注，琴柳、夕、砾无备注。
- 独立审查（2026-09-11，只读，针对早期完整描述版）：机制判断、核心成员计数 35、缺口分类与新增计数均成立；17 条文案无硬性编造；当时提出重复/膨胀、决策偏离、流程缺口与内部接口副作用等意见。后续评估将巫恋、孑的合并明确为正常范围扩展，并采纳指针式及下述验收要求；该审查不代表当前改写文案已获独立复核。

## 风险与边界

- **输出增加**：备注全局渲染到任何命中卡，组合名查询一次返回多张成员卡。新增卡采用短导航减少重复，不以 notes 数量增加本身触发压缩或预算调整。
- **内部接口影响**：store.ts 的 matchTermQuery 会匹配 card.notes，故新增备注可能改变 queryOperators 的 termQuery 命中（该接口不在工具面内，仅供历史调用者与回归）；本计划的命中集合与路径不变承诺仅针对 facts_search。
- **漂移风险**：operator notes 无 expectedHash，guides/references 成员练度或边界变更不会触发校验，存在静默漂移；指向式与来源注释可降低风险，不因本任务引入哈希字段。
- **提示不等于送达**：备注是被动线索，模型可能不跟进（上一轮 S07 复现显示收益有上限且非唯一通道）。
- **成员身份易混淆**：阵营/词条命中集合大于组合成员集合（如正义骑士号、新约能天使、浊心斯卡蒂），补备注前须确认成员身份。
- **不宣称穷尽**：开放组合（龙舌兰组、赤金工艺组、泡泡组、水月标准化组、莱茵科技）不按显式名单排除可适配成员。
