# PRTS 基建机制公式爬取计划

> 创建日期：2026-09-03
> 状态：施工中
> 上游：`docs/draft-prts-crawl-scope.md`（评估版草案，已定稿转为本 plan）；`docs/draft-prose-rewrite-scope.md`（v3 取材范围，本 plan 为其 A 层来源方案）；`docs/plan-hybrid-facts.md`（R5 事实查询）

## 目标

从 PRTS（MediaWiki API）抓取 **8 个基建机制页**（总览 + 控制中枢/发电站/制造站/贸易站/会客室/办公室/宿舍），**一次一页**产出落位 `knowledge/base/` 的 A 层机制公式 md（每条带页面出处），作为被删散文（`docs/0-规则`）重写（v3）的基础规则真源。技能数值/加成/叠加标注一律以 references（`knowledge/references/`）为准，不爬后勤技能一览/store。

## 非目标

- 不爬 `后勤技能一览` / `后勤技能一览/store`（技能数值以 references 兜底，已有来源）。
- 不做 B 层（公孙体系）/ C 层（散件归类口径）/ F09 精2质变清单 / F10 9 步次序结构（属后续人工/其他来源）。
- 升级表**不做整表**：仅取**等级范围 + 本设施机制公式实际引用的参数**；丢弃升级素材（无人机/建材）、建造上限、可用舱室位置、好友位、降级限制、升级条件（前置设施）。
- 不做来源追溯（revision id / 版本注记）、不做与基线 spec（`rag-answer-baseline` F05/G02）的 reconcile、不做知识消费方（RAG / SKILL.md 接回）——均不在本案，**本案仅作人工撰写的源数据替代**。
- 不抓干员页/角色数据页（与 references 同源，冗余）。
- 一次性脚本（`dev-temp/`），不设 fixture/单测门禁，质量门槛人工控制（散文无法量化）。

## 架构分析

- **痛点**：散文层（`docs/0-规则` 等）已于 2026-09-03 删除，`knowledge/references/`（数据层）为唯一真源，但**无任何机制公式**（如无人机 6 分钟/架、面板 `1+X+Y`、订单上限 6/8/10、心情恢复公式等）。A 层 F01–F10 需机制客观事实，数据层无法自证。
- **选型**：PRTS 为社区维护的机制 wiki，MediaWiki API **开放无需认证**——`action=parse`（单页 wikitext）与 `action=query&prop=revisions`（批量）均返回标准 JSON，已实测可行（2026-09-03）。机制参数以 PRTS 为准，一次抓取 + 人工清洗成 `knowledge/base/`，替代人工手抄。
- **规模现实**：8 页（单页最大 ~8.6KB，无大负载），可合并为 2 个批量请求；产出 8 个 md（~60KB），无需独立 INDEX。

## 实施方案

> 按实际依赖顺序，**一次一页**；无真实前置关系的步骤可并行推进，但每页须完成「抓 raw → 清洗产 md → 对标 §4 映射」闭环。

1. **抓取管线** `dev-temp/prts-crawl.mjs`（一次性，不入库）：
   - 端点：`https://prts.wiki/api.php`；按决策 B **一次一页**，用 `action=parse&page=<title>&prop=wikitext&format=json&formatversion=2` 逐页抓取（脚本内依序执行 8 页；`action=query` 批量能力留待需要时启用）。
   - 中文标题 UTF-8 percent-encoding；UA 标识 + 1–2s 间隔。
   - 产物：`dev-temp/prts/raw/<title>.json`（含 wikitext + 抓取时间戳），不入库、不做版本管理。
2. **逐页清洗 + 产出**（一次一页，顺序=附录 A 编号）：每页读取 raw 后按 `附录 C` 模板人工清洗为 `knowledge/base/机制-<设施>.md`：
   - 剥离 HTML/样式 span 保留文本；模板参数提取（`{{color|#0098DC|+20%}}`→`+20%`、`{{道具图标|赤金|1|50px}}`→`赤金×1`、`{{popup|…}}`→内联注记）；`tabber` 转小节、wikitable 转 md、未知模板宽容降级。
   - 「升级表」仅取等级范围 + 本设施实际引用参数列，**按列名匹配**而非列位置；素材/建造上限/舱室/好友位/降级/升级条件整列丢弃。
3. **逐页核对**：每页 md 与 `附录 B` 映射表逐条比对，差异入「与草案差异」列；机制数值以 PRTS 为准。
4. **闭环**：8 页全部产出后，与 `draft-prose-rewrite-scope.md` A 层逐条闭环核对，差异入 notes。
