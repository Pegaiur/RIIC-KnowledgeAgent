## 决策偏离

### 2026-09-05 — 明确单次回馈的决策来源

- **背景**：独立审查认为单次回馈上限合理，但 ADR 原措辞容易把具体次数归为用户明确要求。
- **选项**：维持模糊归因，或区分用户确定的回馈范围与实施方案选择的次数上限。
- **决策**：采用后者；已回馈 ADR-005，行为不变。
- **影响**：固定 auto 和正常工具循环保持原决策，单次回馈的理由可独立复核。

## 意外发现

### 2026-09-05 — 截断检查与工具执行的优先级存在歧义

- **发现**：原计划同时规定有工具调用就处理批次、截断则异常退出，未明确两者先后。
- **影响**：已回馈 spec：保存响应与费用状态后先检查截断及协议完整性，再准入工具。增加截断响应含合法前缀调用和残缺参数的验收，要求零执行、预算不变、记录保留。

### 2026-09-05 — 成功响应也可能缺少有效 usage

- **发现**：原计划仅明确网络失败时的未知用量；当前解析会把缺失字段补成 0。
- **影响**：已回馈 spec：HTTP 200 同样校验输入/输出用量，保留已知分项，未知部分明确标记，汇总不冒充完整费用；加入缺失、部分、无效和明确零值的验收。仅计量不完整不自动重试模型。

## 阻塞与解决

### 2026-09-05 — 计划提交与合并门禁的范围

- **症状**：正式计划含未完成验收项，文档检查 D1 会报错。
