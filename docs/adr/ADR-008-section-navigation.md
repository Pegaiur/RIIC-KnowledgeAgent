# ADR-008：增加原文小节阅读能力

- 日期：2026-09-08
- 状态：已实施

## 背景

搜索命中片段不等于获得整篇机制文档的条件与边界，现有完整词条 facts 查询也不能替代阅读。现有 H2/H3 切块及长块首尾截断不适合作为无损阅读目录。

## 决策

保留检索 chunks/index；从同一manifest原文快照建立H1–H6小节目录。增强RAG展示的标题上下文与有限导航，增加独立 read_section 函数。模型按需读取，沿用auto、call ID关联与共享预算；仅bm25/hybrid/both暴露。输入工具协议递增，历史结果保持可读。

## 理由

分开“搜索定位”和“读取原文”能提供明确的继续取证路径，同时避免改变排序、扩大topK或自动塞入整篇文档。保留实际来源和连续分页，便于模型读取缺失的小节。

## 备选方案

- 只扩大topK：不能保证同一文档的缺失边界被召回，会增加无关片段。
- 自动拼接所有相邻章节：无法区分当前证据需求，增加每次搜索输入。
- 修改现有切块至所有标题级别：同时改变检索基线，超出本轮能力增量。

## 后果

新增语料目录类型、执行器上下文和工具接口，需同步schema/观测兼容。模型可能不选择阅读或多用工具，实际质量与费用收益需后续实跑观察，不由接口设计保证。
