# ADR-022：渐进披露的阅读、关联与默认送达契约

- 日期：2026-09-15
- 状态：已决策
- 替代：ADR-008 的运行时 read_section 接口；ADR-013 决策 2 的默认全文扩展；ADR-018 的恒定目录注入；ADR-020 的格式 v1、提示与 linked 展开方式

## 背景

全文默认送达时，命中范围与模型需要的证据范围不一致，原文阅读常成为重复获取。关闭扩展的既有观测显示模型会主动使用阅读，但未证明回答或费用稳定改善。关联展开没有分页，且原文/事实需要分别调用；现有注解缺少作用域和概念引用，无法表达共享定义与精确条目。

用户要求将整个渐进披露方案定稿，补齐 read、scope 与各格式契约。目录迁移采用 ADR-021，关键词目录压缩仍是独立议题。

## 决策

1. 运行时以 read 取代 read_section，参数为 section_id、可选 offset 和 facts_offset，默认均从 0 开始。每次读取目标原文子树与该范围的明确关联；不保留 linked 或原文专用模式。未知 ID 不模糊匹配，旧工具名只作历史读取兼容。
2. 两个偏移分别为 UTF-16 正文位置和最终去重对象序号；返回两侧完成状态、下一偏移、总完成状态与可复制 next_call。结束的一侧用总长度/总对象数作为下一调用参数，不因继续另一侧而重复送达。完整范围读完不表示问题已覆盖。
3. read 的全部 data 受 maxContextChars 约束，正文每页最多 6,000 UTF-16 字符。先保必要元数据和下一个完整事实，再分配正文与其余事实，导航用余量；不截断卡片，不自动扩预算，不输出无法前进的续读。单对象超过整页可用容量显式报错。
4. 关联仍位于 knowledge/prose-links.json，格式版本升至 2，按文件、标题路径、可选出现序号定位，scope 必填。section 只作用于登记节点，subtree 作用于登记节点及后代；read 父范围包含子树登记，read 子范围只继承祖先的 subtree 登记。scope 不改变原文范围或 BM25。
5. operator 引用返回完整卡；skill 精确投影到指定持有关系及被替换链。同卡聚合并保留来源，完整 operator 卡覆盖同卡技能投影。概念用 kind=concept 加文件、标题路径及可选条目名称/出现序号定位当前原文；同名定义必须显式消歧。来源只取 manifest，不建第二份定义，不递归展开正文名字。
6. 原文与关联取同一运行快照。一次 read 只算一次外部 attempt，实际送达正文/卡片任一证据才算一次 success。readDelivery 与 RAG 片段范围观测接通 trace、records、meta/report 和 snapshot，提示与实际证据分开；历史缺字段保持不可用。
7. expandFulltext 默认 false，RAG 返回命中 H2/H3 块及必要阅读 ID；ID 与范围元数据先于正文，不能因导航预算不足而丢失。保留显式 1 的全文回退，不设中间档。query 精确词条触发的 RAG 内部 facts 附带及独立 4,000 字符额度继续沿用 ADR-013。
8. 增加 injectKeywordCatalog 默认 false 及 --inject-keyword-catalog 0|1。关闭时不读取目录文件，开启时正常追加且缺失报错；catalog 生成与 --check 独立。CLI、fallback、meta/inputs/snapshot 同步，不应用目录压缩 stash。
9. 工具定义版本 14 → 15，facts 结果版本沿用 ADR-021 的 8，prose-links 为 2；原文目录版本/ID 算法不变。历史输入、快照与旧工具名不改写；新增可选观测和配置沿用兼容追加方式，不新增哈希。
10. 散文在迁移和门禁闭合后按窄命题分批拆分，配套精确关联、gold/spec/目录更新。真实模型与检索指标仅作观测，不设质量通过线；全流程的字段、格式、边界与测试以实施计划第 4–8 步为施工契约。

## 理由

保留命中正文，可以让模型直接利用已有证据，再通过同一工具补读原文和事实。分开正文字符偏移与对象偏移，避免混合计量导致漏页或重复。显式作用域和来源位置能够区分父子共用关系及同名定义，精确技能投影减少把整张卡当作局部证据的误读。

目录开关把成本与注入行为变为可记录的配置，不把缺少收益证据解释为目录永久无用。保留全文回退及原有 query facts 通道，使行为边界清楚且可观测。

## 备选方案

- 仅改工具名或提示词：不采纳，无法解决容量、作用域与精确定位。
- RAG 只返回标题：不采纳，会强制每个查询再读，当前保留命中证据更符合渐进取证。
- 单一 offset 混排正文与卡文本：不采纳，字符和对象单位混淆，容易切断卡片。
- 所有祖先关联自动继承：不采纳，必须由作者用 subtree 明确声明。
- 概念按名称模糊匹配：不采纳，来源内存在同名不同定义。
- 在 read 增加原文专用开关：不采纳，首版保持统一行为；可通过已完成的偏移继续另一分区。
- 按可用空间暗中恢复全文：不采纳，使用明确布尔配置，避免送达边界难以解释。

## 后果

- 新接口和格式是显式迁移，调用方、导航示例、Agent 指令、记录消费者与测试须共同切换。
- 引用范围变宽或卡面变长可能增加调用与费用；超大对象会显式失败，不能以正文已返回掩盖事实未送达。
- scope 合法与对象存在性校验不能证明正文断言正确，标注仍需人工审阅。
- 本 ADR 为已决策，尚未实施；真实模型观测需在工程全绿并满足费用执行授权后开展。
