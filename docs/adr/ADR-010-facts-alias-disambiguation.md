# ADR-010：facts 别名、集合词条真源与同名全部返回契约

- 日期：2026-09-09
- 修订日期：2026-09-10
- 状态：已实施
- 替代：局部扩展 ADR-007 的精确匹配契约，新增已确认干员别名与确定搭配集合；保留六类规范查询及同名全部返回，不含子串/模糊兜底

## 背景

`facts_search` 当前精确查询干员、技能、技能组、设施、阵营和职业，并返回同名跨类别并集。`RecordCard.aliases` 恒空，[ADR-002](ADR-002-facts-record-card-source.md) 与R5-2留有名称真源缺口。扩展入口需要保留集合身份、成员归属及多个来源，不能只用一份无路径的卡片列表表达。

正式 guides 的搭配候选盘点为19个（贸易9、制造8、跨设施2），含红云任选分支、裁缝任选、五选四及开放技能类别成员。简写合称不能直接等同于完整搭配，例如“银崖”不自然包含喀兰贸易组其他核心。

用户于2026-09-10明确：简写合称暂不支持；多人集合只支持确定阵营与搭配；反问及消歧措施不在本计划范围内，仅保留同名重叠全部返回。本次修订取代本ADR先前的相关策略设计；运行时实现已按计划完成，发布元数据收束尚未执行。

## 决策

### 1. 范围与真源

- 保留六类规范词条查询，新增证据充分的干员别名与正式搭配规范名。别名若有多个已确认目标，全部登记、全部返回，不选择默认目标。
- 不支持德狼、能蕾、银崖、孑拉德等简写合称，不以别名或旧称绕道接入；未收录时不拆词、不猜测成员。
- 不新增人工子串对入口，不登记/验收31组子串对；“临光”不是“耀骑士临光”的同名索引键，不因子串包含关系扩展结果。
- 不设计反问、设施/上下文选择、指代确认提示或相关回归，不修改 `knowledge/AGENTS.md` 与旧检索语料的相关规则。
- 人工登记在 `bench/src/facts/curation/terms.ts`，独立于九设施CurationBatch；不回写RecordCard.aliases，不新增哈希字段。阵营成员仍来自事实卡索引，不另建人工副本。
- 用户最新裁决优先；身份/设施/阵营/技能以references为准，搭配定义以正式guides为准。生成的名称说明和raw只可提供核对线索，不解析为运行时源、不反向覆盖正式知识；两份新raw仍不纳入。
- evidence记录来源相对路径与小节标题，来源变更同步复核。19个搭配候选按具名清单确认登记或缺证原因，不以数量代替审定。

### 2. 数据身份与搭配边界

- 干员目标采用 `operator:<canonical>`，搭配采用 `combo:<规范名>`；不引入阶段2的新类别或技能身份体系。
- 搭配保存显式成员及核心/重要/次级/挂件/可选角色、条件摘要、来源与覆盖范围。保留原有练度、设施分工、任选数量等条件，不实现条件求解器，也不据成员卡推导完成度。
- 技能类别等开放成员范围以文字保留并标注非穷尽；阶段1只返回明确登记的卡片，不动态扩充名单。
- “龙门中枢组”保留该规范名，成员为斩业星熊、诗怀雅、陈及正式guides分层，不另保留同名二人合称。
- 红松骑士团相关搭配使用“红松骑士团组”为规范名；它与“龙门中枢组”是独立身份，不互相归一。
- 历史名称区分已证实同义旧称、明确废弃、暂不支持和推荐层隐藏。仅证据充分的同义旧称直接指向已登记搭配；拒绝须有明确废弃依据。默认不推荐不等于无效名称，不要求raw的18个历史名称全部入表。
- 禁止同一身份重复定义、重复目标/成员、悬空目标、旧称链/环及失效证据；允许同词对应多个身份，不施加全局字符串唯一限制。

### 3. 同名全部返回

query仍为唯一输入，trim后精确查索引。一次查询收集六类规范词条及已登记别名、搭配、旧称的全部命中，不以首个命中提前返回，不按类别或上下文择一。

- 同词命中规范名与别名时，保留正式名结果及别名全部目标。
- 同词命中阵营与搭配时，保留两套独立成员归属。例如“叙拉古”分别标注阵营及搭配，不能混成一个无分类集合。“企鹅物流”在现有真源中未登记同名阵营，仅返回已登记搭配，不为构造重叠补造阵营。
- 全部路径共享的卡片仅输出一次，保留每条路径身份、来源及成员角色；路径按固定类别顺序、卡片按现有卡序输出。
- 别名/旧称按目标身份直接取卡或搭配，不把目标名称递归作为新查询；具名成员不自动展开为异格。
- 旧名拒绝只作用于该路径，不屏蔽同词其他合法命中；尚未支持的resource/rule等类别不伪造命中。

### 4. 查询级结果与序列化

结果承载原查询、命中路径列表（精确/别名/组合/旧称/拒绝）、每条路径的目标身份及来源、成员信息、去重卡片、条件摘要和覆盖范围。归一目标放在路径内，不用单个全局归一词覆盖多个目标。

| 场景 | 输出 |
|---|---|
| 规范词条 | 精确词条、命中类别及完整卡 |
| 干员别名 | 别名与所有登记目标，例如“维娜 → 维娜·维多利亚” |
| 搭配规范名 | 搭配身份、成员角色、条件摘要、来源与覆盖范围 |
| 同词多身份 | 全部命中及各自成员归属；共享卡片只输出一次 |
| 同义旧称 | 原词、该路径归一目标与结果 |
| 明确废弃名称 | 拒绝原因及依据 |
| 未登记词或简写合称 | 未收录精确词条，不列猜测成员 |

输出仅提供客观命中信息，不增加指代判断字段或提示。查询级信息进入工具结果元数据，不从正文反推类型。

`matchedCount`为全部路径去重卡数，`returnedCount`为实际返回卡数。保持完整整卡返回，不引入截断；complete=true表示本次匹配卡已全部返回，不代表开放成员范围穷尽。未知与纯拒绝均为empty、executed=true、计数0、complete=true，由路径与正文区分；有合法卡则success。协议/运行错误及预算计量沿用既有规则，正文、hitIds/injectedIds、trace和落盘结果一致。

### 5. 版本与实施边界

TOOL_SCHEMA_VERSION升为7，FACTS_RESULT_VERSION升为3，工具描述、元数据、测试和观测输出同步。facts模式仍只开放facts_search，不新增参数，不修改Agent决策契约。不为本任务生成新快照或启动付费测评。

本阶段不修改历史lookup；R5-2只处理已完成的当前facts部分，不能宣称其余历史能力已恢复。阶段2新类别、关系边、数值化和简写合称后续另议。

## 理由

- 同名全部返回延续当前精确查询并集行为，不需要选择优先级或上下文策略。
- 简写合称后置，避免扩大用户词语的成员含义。
- 条件摘要和覆盖范围保留组合边界，无需提前建立计算模型。
- 查询级多路径信息保留身份与成员归属，支持零卡拒绝及重复卡计数。
- curation独立于生成文件，来源定位及同步核查降低成员表漂移风险。

## 备选方案

- 命中首个身份后返回：不采纳，会遗漏同名其他结果。
- 依据子串自动或人工扩展候选：不在本阶段范围，同名以索引键精确相等为准。
- 简写合称映射整套搭配：不采纳，用户明确暂不支持。
- 默认不推荐即拒绝名称：不采纳，推荐策略与查询事实不同。
- 完整条件图、回写卡别名或运行时解析散文：不采纳，超出当前最小实施范围。

## 后果

需修改登记校验、store及调用者、查询级结果、执行器元数据、序列化、工具描述与回归测试；不修改Agent契约。测试覆盖同词多目标、多类别、去重路径、子串不扩展、具体成员/条件、非法数据与协议，不以反问行为或答题正确率验收。

本轮修订已按最新范围实现并完成回归；此前独立审查中的规范名连写已修正，旧语料反问规则冲突不在本计划处理。计划尚未冻结归档，发布元数据收束另按发版流程执行。
