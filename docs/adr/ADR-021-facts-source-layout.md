# ADR-021：facts 真源目录归并与事实出口

- 日期：2026-09-15
- 状态：已实施
- 替代：ADR-013 决策 1 的 references 检索范围及 includeSkillTables 选择；ADR-002 中依赖 references 目录的真源位置约定

## 背景

references 同时容纳机械事实、类别/歧义说明与开发来源记录。默认 RAG 已排除九份技能表，但模型阅读目录仍包含这些文件。名册和同描述组大部分已被 facts 吸收，继续以大块原文检索的职责不清；技能注记和同描述依据尚未完整显示，不能直接删除其唯一可见出口。

用户确定将退出检索的事实输入移入 raw、保留检索的两份资料移入 guides、移除数据源开发文档，撤销 references 目录，并允许限定的旧门禁同步延至分支收尾。

## 决策

1. 九份技能分片、名册、技能等价组共 11 份平移至 knowledge/raw/，保留文件名和单一维护位置；facts 明确读取这 11 份文件。类别、歧义平移至 knowledge/guides/，类别仍为 taxonomy/目录的单一输入，歧义仍提供现有登记的 evidence。raw 不递归消费，不进入 RAG 或模型阅读目录；RAG manifest 拒绝这些范围外路径，gold 另用明确的真源定位装配。
2. knowledge/references/数据源.md 作为开发文档移除；必要来源与缺口依据写入实施笔记，随计划归档，不在 knowledge 新建副本。当前生成器缺位的事实如实说明，不承诺运行不存在的脚本即可重建。
3. 先接通技能 products/professions/referencedTerms 的投影与显示，保留 target 原始注记；显示等价组技能名、设施及共同效果原文，明确仅为描述相同，不代表完整效果相同。名册身份边界移入查询 Agent 指令，不把一次空检索等同于对象不存在。
4. FACTS_RESULT_VERSION 由 7 升至 8；同一卡片格式被 facts_search、RAG 附带及关联读取共用。既有查询候选、同名全部返回、tags、效果、解锁和替换语义不变；四条未登记合称不新增入口。
5. includeSkillTables 退出新运行配置，CLI 显式出现旧参数（含显式 0）即报中文迁移错误，并按 bench CLI 现有口径以退出码 1 结束；历史字段可读，不静默重新解释。新 inputs/meta/snapshot 可选记录 retrievalScope="base-guides"，不新增哈希字段。
6. 类别/歧义保留原始字段与定义，采用两份精确路径的术语检查例外；其它 base/guides 继续检查。维护说明与冲突指令可按现有事实/工具契约修订，不在迁移中改成员和数值。散文中的旧回指改成 facts 能力表述，不引导模型访问 raw。
7. gold 定位真源与 RAG 检索范围分离；真源存在但被排除的 gold 仍计分母。当前规格更新路径，历史运行、冻结文档及快照保持原事实；不因目录变化改答案判定。
8. 保留用户 2026-09-15 授权的阶段例外：指定旧 gold/白名单/基准完整性断言、关键词目录一致性与历史基线口径处置可延到分支收尾。manifest、读取和生成器路径及新行为测试随迁移闭合，TDD 与每批全套测试仍执行。例外期间不可合并、发版、登记新基线或执行付费试验；全部延后项在计划验收前转绿。

## 理由

职责按实际消费者划分，保留 facts 真源与机械关系，同时避免把 raw 理解为统一的未核验状态。先补出口能够保留迁移后需要的精确信息；保留类别/歧义检索可以继续交付尚无 facts 定义出口的内容。

按事实结果和工具定义分别版本化，避免内部路径变更被误解为自然语言查询扩展。退役参数明确报错，比接受一个无法改变新检索范围的开关更可核查。

## 备选方案

- 保留 references 目录并继续混合消费：不采纳，用户已确定目录分工，继续混用难以约束模型阅读范围。
- 将所有内容移入 raw：不采纳，类别/歧义尚有独占定义与说明出口。
- 将数据源也移入 raw：不采纳，开发溯源不应继续成为语料文件。
- 拷贝一份新真源并兼容旧路径：不采纳，会制造双份维护位置和隐式回退。
- 迁移时立即修完所有旧门禁：常规规则仍要求同步；本次按用户限定例外分阶段完成，不推广为仓库通用规则。

## 后果

- 文件、加载器、生成器、CLI、留档、规格、指令与维护规则需要配套修改，详见实施计划。
- 未拆正文时默认 RAG 预计由 145 块变为 121 块；范围减少不是质量提升证据。
- 新卡面可能变长，所有使用方必须按最终渲染长度遵守各自容量契约，不能静默截断事实。
- 本 ADR 已实施（2026-09-18 随计划归档登记）。旧 ADR 其它有效条款保留，不回写历史记录或作前向引用。
