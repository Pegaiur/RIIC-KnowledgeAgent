# ADR-023：RAG 采用文件目录树与命中预览

- 日期：2026-09-17
- 状态：已实施
- 替代：ADR-022 决策 7 的默认正文展示、决策 9 的文档范围 ID 形态；其余阅读与计量契约继续适用

## 背景

RAG 结果中的文件路径、阅读入口与导航说明多处重复。用户选择按文件展示完整标题结构，命中小节提供短预览，再按需要读取命中范围或整篇。

## 决策

1. 默认结果为 Markdown 目录树。根行提供文件标题、`doc:<文件名>` 与全文字符数；命中节点提供小节 ID、◆ 标记及登记的关联对象数。其余节点展示标题和层级，一级标题由根行承载。
2. 命中预览取同一原文快照内该块的前 100 个 UTF-16 字符，保留换行与缩进，不拆代理对；引用行区分预览与目录，截断标记给出原文块长度。
3. 容量依次分给命中 ID 与祖先链、预览、其余结构。非命中子树可折叠，条目整行保留或省略，子条目随父条目展示。◆ 表示检索命中；`injectedIds` 和 `fragmentRanges` 仅登记实际送达的预览。没有预览时沿用容量错误，独立 facts 附带仍按实际证据判定成功。
4. 默认结果不再展示父级引导与独立上级入口。关联提示放在命中行，`linkedEntries.written` 继续按提示行是否实际写入判定。历史 `parent_lead` 记录保持可读。
5. 文档范围 ID 改为 `doc:<文件名>`，白名单校验跨目录文件名唯一；旧的带目录 ID 按未知 ID 处理。小节 ID 算法、read 分区与双偏移分页继续沿用。SectionDirectory 以 `outlineFor` 提供文件目录，退役展示专用的 `contextFor`。
6. 显式全文扩展继续返回原文及续读信息，块头以文件名标识来源，目录补充不重复预览。工具定义版本升为 16，记录字段与历史输入保持原样。

## 理由

目录层级表达文件结构，短预览提供命中内容线索；阅读入口集中到命中范围与整篇。预览和片段登记共用原文切片，使展示内容与计量坐标一致。

## 备选方案

- 保留压缩索引表：首轮已实现，最终选择目录树表达完整标题结构。
- 改用 JSON：键名与正文转义增加文本，当前结果以可读文本组织。
- 为所有标题保留 ID：增加导航文本，当前按命中范围与整篇提供入口。

## 后果

- 非命中小节的内容通过整篇阅读取得，也可继续检索或使用 read 返回的导航。
- 默认送达正文减少，后续阅读量与回答效果通过实际运行观察；本地重渲染只验证文本和工具契约。
- 文档范围 ID 是显式迁移，调用时使用当次工具返回的 ID。
