## 决策偏离

### 2026-09-18 — 依用户澄清修订来源与核查职责

- **背景**：计划原将所有外部仓库降为线索，同时尚待选择 facts 唯一源，未表达用户实际采用关系。
- **决策**：facts 唯一上游固定为 arkntools/arknights-toolbox-data 的解包数据；lejciy/arknights-base-vault 是应纳入本库的散文来源，按主题整理和改写。散文承载解包数据与游戏实践形成的理解，由人类与 Agent 联合审阅，不要求严格机械断言或逐句字段映射。
- **影响**：清洗脚本及 RIIC-Web 镜像仅作为实现参考；本地 11 份 raw 是当前 facts 输入，不能仅凭已有门禁宣称来源映射已验证。原 inbox 正文机械断言方向按用户决定关闭，格式、结构与送达检查继续保留。

### 2026-09-18 — 收口计划交付与目录处置

- **背景**：旧执行顺序把主题导入列为后续工作，验收却要求完成未限定范围的导入。
- **决策**：本计划限于规范落位、facts 映射评估与迁移处置；具体主题批次另定采用范围。当前决定不迁移存量路径，新内容沿已定分类落位。
- **影响**：保留完整历史候选与承载评估，移到附录；更正已交付的清单校准和试点进度。历史上仅因 facts 暂缺而暂缓的散文，可按新口径联合审阅，不自动排除。

## 实现调整

### 2026-09-18 — 长期规范同步与验收边界更正

- **plan 原文**：每个内容批次独立审查，但写作 spec v1 未要求每次由第二名 Agent 复核；现有门禁被概括为保证 facts 正确。
- **实际做法**：spec 升为 v2。实质新增、导入及机制、条件、建议改动由独立 Agent 复核；错字、格式和不改含义的措辞修订由当前 Agent 自查。人类参与采用目标、实践判断和争议取舍，已有决定直接沿用。根 AGENTS.md、术语规则、inbox 与 ADR-020 内容维护引用同步。
- **原因**：让长期规范承载共同要求，避免活动计划归档后丢失口径，也避免每次细小修订触发完整审稿流程。
- **后果**：check:reference-projection 仅能验证公共练度说明投影，prose-links 与 read 仅验证各自结构或送达契约；完整上游映射仍待计划步骤 2。该评估需记录固定解包提交、源文件及对象字段、11 份输入覆盖与转换、缺口和后续实现范围，不在本次修订中虚报完成。
