## 决策偏离

### 2026-09-08 — 指令总长度略增，但长段落拆为短规则
- **背景**：目标是简短、可执行，同时要新增条件保留、名单一致性、read_section 语义和作答格式等通用规则。
- **选项**：
  - A: 严格压缩总字符数，删减原有规则含义。
  - B: 保持原有约束不丢，把 7 条长段落拆为 11 条短规则并分三段。
- **决策**：B。按 LF 归一后，指令正文由 1071 字符变为 1122 字符（+51，去尾换行后 1070→1121）；增加部分全部是用户明确要求的通用规则，未重复原有要求。
- **影响**：单条规则更短、可执行性更强；字符数不用于推断模型 token 或费用变化。

### 2026-09-08 — 不引入强制阅读或自检
- **背景**：已知观测显示补读与分页收益尚未证明。
- **决策**：只写“缺口已定位到小节时用 `read_section`、有后续页按 `next_offset` 续读、`complete=false` 不等于必须读完”，不写“至少读一次”或固定自检轮次。
- **影响**：工具选择仍由模型按证据缺口决定，不改变预算与 agent loop。

## 实现调整

### 2026-09-08 — 同步更新 agent.test.ts 的契约断言
- **spec 原文**：重写 `knowledge/AGENTS.md` 的取证与作答规则。
- **实际做法**：`bench/tests/agent.test.ts` 有两条对旧措辞的逐字断言（“技能的解锁与提升”“具体事实冲突时以更直接、对象更明确的记录为准”）；改为断言新契约的等价语义（“保留原文条件与限定”“冲突时以更直接、对象更明确的记录为准”），不新增测试。
- **原因**：断言对象就是被重写的指令正文，不更新会因措辞变化误报；断言内容仍是通用证据边界，不涉及题号或固定答案。
- **后果**：提交范围包含该测试文件；`pnpm run test` 340 项全通过。
