# 散文重写取材范围（v3）—— 草案

> 创建日期：2026-09-03
> 状态：草案（draft）——基于「20 题答覆充分性」评估的取材清单；定稿后转 `plan-*.md`
> 关联：`docs/plan-hybrid-facts.md`（R5 事实查询，散文重写为其中 v3 预登记项）；`docs/spec/rag-answer-baseline.md`（F/G 批参考要点待 P0.4 以 references 真源重制）；`docs/archive/plan-facts-source-purge.md`（散文已删）

## 背景

- 语料现状：`knowledge/references/`（数据层）为唯一真源；散文层已于 2026-09-03 整体删除（`arknights-base-vault/docs/0-规则/`、`arknights-base-vault/docs/2-体系/`、`arknights-base-vault/docs/4-散件工具人/`）。
- **20 题充分性评估结论**：刨除散文后，数据层能提供「技能数值 / 成员枚举 / 解锁门槛」，但**无任何一题能被纯数据层完整回答**；约 9 题只能答「枚举/数值」子问，其余 11 题（机制公式 + 全部 S 类）在数据层无对应内容。
- 缺口分三类：**客观机制规则**（数据层无法自证）、**公孙体系判断**（散件判断层）、**散件归类口径**（哪些算散件、谁带条件）。三者即本草案的取材范围，本质是被删散文的重写范围。

## 目标

界定散文重写（v3）需补齐的**客观机制规则 / 公孙体系判断 / 散件归类口径**取材范围，逐条对齐 20 题，作为重写产出物清单。只覆盖 20 题闭环所需，不扩大到全部游戏机制。

## 非目标

- 不重复数据层已有的部分：技能效果数值 / 成员枚举 / 解锁门槛 / 派系成员表（references 已存；重写**不得采信**散文数值，遵循「数据引用以 references 为准」）。
- 不做上游接入：`数据源.md` 已知缺口（补源缺 20 技能 / 10 干员字段）仅作标注，不补数。
- 本草案只定「重写写什么」，不含「判断层如何组织/转录」（SKILL S3 结构化另议）。

## 取材范围

### A. 客观机制规则层（← 原 `arknights-base-vault/docs/0-规则/`；服务 F01–F10）

- **发电站**（F01）：无人机基础速率 6 分钟/架、充能 `6÷(1+加成)`、只受发电站干员影响、多站独立结算、溢出丢弃不停摆且心情照常、+5% 保底与 10/15/20 档位
- **制造站**（F02）：面板 `1+X+Y`（X=每进驻 1 名非注意力涣散干员+1%（PRTS 无「满员+3%」）、Y=技能）、技能类型学、仓库容量维度 24→36→54、心情消耗 `≈1−0.05×(人数−1)−技能减免`、槐琥团队精神消除
- **贸易站**（F03）：订单上限 Lv1-3=6/8/10 与技能加上限（银灰+4、可颂/拜松/衡沙+1）、赤金分布 Lv3 30/50/20（裁缝 α→15/30/55、β→5/10/85；Lv1 仅 2、Lv2 无 4）、特殊订单优先级（佩佩>可露希尔>尤里卡>但书>龙舌兰）与只触发一个、孑市井之道（每 10% 他人效率→上限−1、每差 1 笔+4%）、「上限≠处理速度」
- **会客室**（F04）：线索碎片/交流机制（交流期停收=空窗）、传递不消耗与每日限制、固定双人 combo（忍冬+铃兰/凛视+提丰）、见行者不建议
- **办公室**（F05）：单人站（上限恒 1、电力 10/30/60）、基础刷新~12h、+50%→~7.7h、公招取向与前置（斥罪 19.2h 不适用 24h 班、凯尔希·思衡托需 5 处设施精英）
- **控制中枢**（F06）：每进驻 1 人全局−0.05/h、电力恒 0 不可降级、副手不算进驻、全局光环「同种取最高」、派系计数取决于工作设施而非中枢、5 席竞争、歌蕾蒂娅心情 ~3.2/h/短班~7.5h
- **心情与宿舍**（F07）：工作消耗 1/h 与减免结构→0.65~0.85/h、恢复公式（等级基础 `1.5+0.1×等级`、氛围 `0.0004×值`、满氛围表 2.0/2.5/3.0/3.5/4.0）、额外消耗（德克萨斯+0.3、归零+0.25）、12h/6h 排班与瓶颈=宿舍容量
- **练度与技能**（F09）：一至三星 Lv.30 满级解锁语义化为「星级→解锁表」（SKILL 零散需成表）、精1→精2 质变清单（但书/裁缝β持有者/巫恋核）
- **buff 叠加次序**（F10）：9 步次序（全局资源→固定加成→中枢跨房→上限汇总→差值效率→他人效率→归零吸收→订单类型→心情）、归零先于裁缝、灵知先减、雪雉读他人、清零优先（深海 vs 自动化分站）

### B. 公孙体系层（← 原 `arknights-base-vault/docs/2-体系/` + `体系总览.md`；服务 S01–S08）

每体系需：构成 / 核心双人 / 硬性条件 / 数值锚点 / 缺人降级路径 / 班次与房间约束 / 互斥 / 与其他体系关系。

- **S01 243 布局**：243 构成、公孙一图流（中枢/各贸易站/各制造站/发电站满配）、meta_chain 四选一互斥组、中枢 5 席共享
- **S02 怪猎中枢**：火龙S黑角+麒麟R夜刀双核心（均中枢 E2）、消费方=泰拉大陆调查团成员、木天蓼联动
- **S03 深海链**：歌蕾蒂娅中枢 E2「集群狩猎·β」、效率公式 `min(本站深海×全基建深海×10%, 90%)`、2+2 / 1+1+2 锚点、缺人降级、心情 3.2/h 核算
- **S04 巫恋裁缝核**：三人分工（巫恋精2+龙舌兰精2+裁缝β）、归零+45%、效率分档 138/129/124/108/93%、缺人降级
- **S05 自动化组**：承曦格雷伊虚拟电站、温蒂每电站+15%、清流每贸易站+20% 赤金、243/333/153 锚点、缺人降级
- **S06 迷迭香感知链**：迷迭香+黑键核心、感知生产者（夕/絮雨/爱丽丝/车尔尼/令/琴柳）、档位锚点、缺人降级、贸易站搭配
- **S07 红松林经验**：焰尾+薇薇安娜双中枢、灰毫/远牙/野鬃、效率计算（25×3 + 焰尾 + 薇薇安娜）、126% 锚点

## 取材优先级与取舍

- **优先级**：A（机制地基层，F 类闭环）→ C（归类口径，G 类）→ B（公孙体系，S 类唯一出路）。
- 只补 A：F 类可在数据层上闭环，S 类仍全不可答（与 plan-hybrid-facts「v0 只评事实层」一致）。
- 补 A+B+C：20 题可完全回答；其中 A 是机制依据、B 是体系判断、C 是归类口径，三者共同组成重写产出物的完整范围。
- **数据引用规则**：重写中**干员技能维度数值**（星级/解锁/效率/派系/等价组）一律以 references 为准；**机制系统基础参数**（如无人机 6 分钟/架、面板 `1+X+Y`、订单上限 Lv1-3=6/8/10、赤金分布 30/50/20、心情恢复公式等——references 无据，见「数据层已知缺口」与原始上游/被删散文）须在重写时注明来源，不得凭记忆编造。重写文本负责「解释机制、给出体系评价、界定归类」，不承担「数据来源」职能。
