### 已知跨基点差异（与正式基线之间，不构成受控对照）

1. **目录注入**：本基点含 `knowledge/关键词目录.md` 的 17,738 字符常驻注入；正式基线 `bench/results/2026-09-12T15-38-28-892Z-glm-low-default.json` 不含。该差异影响每次请求的输入规模与缓存命中。
2. **扩展开关**：本轮与配对轮均为 `true`，正式基线亦为 `true`。

因此本轮与正式基线之间只能作方向性观察，不声明受控因果；**只有本轮与配对轮之间才是「同一 HEAD、同目录、同语料、只差一个开关」的准受控对照**，且仍需按采样随机性处理（见方法学）。

## 结论

- **机械校验通过**：两轮 90 个 `fulltextRanges` 全部为 `complete=true` 整篇扩展，开关确实生效，不触发停止分支。整篇送达均在 `maxContextChars=12000` 内完成，未出现 `partial` 续读。
- **直答 (a)：expand=true 下 `read_section` 的内容级复读率不可定义为「有复读」，因为两轮 `read_section` 调用数均为 0**（0 复读 / 0 新增 / 0 空结果 / 0 非法 ID），模型在有整篇送达时**完全不需要渐进披露**；对照 expand=false 轮的内容级 1 复读 / 4 非复读（文件级 5/5 复读），可观察到的差异是「是否发起 `read_section`」这一阶跃，而非复读比例的下降。文件级与内容级两套口径在 expand=true 下同时为空集，因此**不存在「两口径不等价」的情形可报告**（任务预设的「expand=true 时两者理论上等价」在本轮因无调用而未获检验机会）。
- **直答 (b)：只差开关的两侧，差异数值如下（同 HEAD、同目录注入、单轮采样，不作因果结论）**——输入 token R1 +1.3%（703,167 对 694,312）、R2 −7.9%（639,753 对 694,312）；费用 R1 +11.2%（0.270641 对 0.243493）、R2 −3.6%（0.234757 对 0.243493）；未缓存输入 R1 +46.0%、R2 +6.7%；输出 token R1 +7.0%、R2 +1.5%；LLM 调用 R1 −4.3%、R2 −10.9%；工具批次 R1 −7.7%、R2 −19.2%；两轮额度耗尽与预算拒绝均为 0；必答计数由 58/13/0/1 变为 R1 60/12/0/0、R2 62/10/0/0，「完整且有据」由 10/20 变为 R1 10/20、R2 11/20（B 侧名单已按 2026-09-15 更正计入 S07）。**两轮在费用上的方向相反（+11.2% 与 −3.6%）**，说明该量级的差异落在采样与缓存波动范围内。
- **对上一轮「token ×2.9、费用 +51%」的归因**：本轮在同基点下打开扩展后，输入为正式基线的 ×2.97（R1）、×2.71（R2），费用 +67.8%／+45.5%，即**该量级的膨胀在开关两侧都存在**；相对同基点同目录的配对轮，输入只差 +1.3%／−7.9%、费用只差 +11.2%／−3.6%。据此可报告：上一轮观测到的 token/费用膨胀主要由**目录注入（及由此变化的缓存命中率）**解释，`expandFulltext` 在当前配置下不表现出同量级的独立效应。该结论受「仅两轮、temperature 为服务端默认、缓存命中率轮间波动 3.5pp」限制，仍不宣称因果。
- **行为层观察（不做优劣判断）**：整篇送达使模型放弃渐进披露（`read_section` 0 次），同时把工具预算花在 `facts_search` 上（R1 5 次、R2 2 次，配对轮仅 1 次）；轮数均值略降（2.20／2.05 对 2.30）。个别题上出现「只靠 facts_search 作答」的路径（R1 的 G02、R2 的 S08），其中 R1 的 G02 因此出现额外断言冲突（地灵被写成无心情代价的 45%），提示整篇扩展并不自动消除事实核查缺口。
- **答案层面**：必答 60/12/0/0（R1）、62/10/0/0（R2），「完整且有据」10/20（R1）、11/20（R2）。两轮的遗漏项高度重合（同一批边界条目），轮间差异主要来自额外断言（R1：F01 雷蛇档位、G02 地灵代价；R2：G02 夜魔练度、S06 塑心资源归类）。本轮不设达标线、不据答错改实现、不指定为正式质量基线；单题补跑未执行。
- **两侧同口径的边界**：配对轮的 58/13/0/1 与 10/20 沿用 docs/exp/exp-no-expand-read-section-glm-low.md 的既有 v4 逐题结论，**未在本轮重新独立复核**；本轮的 60/12/0/0、62/10/0/0 与 10/20、11/20 由本次核查给出。配对轮记录曾有一处口径不一致：其 S07 逐项计数为 3/0/0/0（全满足），却未列入其「完整且有据」名单；2026-09-15 已按该记录自身口径更正为 10/20（含 S07），本文件的汇总、配对差表与本条说明随之同步，其余数字仍沿用其记录。
- **局限**：单模型单档位、单题集；temperature 未设（服务端默认）且仅两轮，轮间波动不可分离为开关效应与采样噪声；额外断言采用抽点回查（两轮合计 54 条）而非逐条穷尽；答案核查为本次人工判定，未经独立复核；`includeSkillTables=false` 使部分需精确心情代价的必答项（F05.3、G02.2）在证据层面不可达；未检验 `partial` 续读路径与容量不足分支。
