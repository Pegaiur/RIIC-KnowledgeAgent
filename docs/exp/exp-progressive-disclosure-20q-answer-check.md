## 结论

- **支持**：在渐进披露新默认配置下，本轮单轮真实运行的回答可按 docs/spec/rag-answer-baseline.md v5 完成全量逐题核查并给出可复算的编号级计数——72 个必答编号中满足 59、遗漏 13、冲突 0、待核验 0，额外断言层面另有 3 处冲突与 1 处未证实；严格口径下「完整且有据」9/20（F01、F02、F05、F06、F09、S01、S04、S06、S07）。工具与送达台账自洽（35 次工具调用 0 拒绝 0 错误、13 次 read 全部成功、0 非法 ID、0 命中未知），使遗漏可逐项归因到「未送达」或「已送达未覆盖」。
- **不支持**：本轮不能支持质量提升或退化的结论。单 provider、单配置、单轮，无对照与重复采样；13 项遗漏中 7 项属必要证据未送达（不归因模型），其余 6 项属已送达未覆盖；额外断言问题不改变已答部分的事实性判定，但按 spec 使相应题目不满足「完整且有据」。不得将本轮计数与迁移前口径基线或其它配置横比，也不得据此计算达标率。
- **观察（非结论）**：遗漏集中在 raw 专有精确数值与小节级机制证据（订单策略与确定时点、中间资源的生成与转化、伺夜会客室每级 +5%）与组合题的「否决/边界/互斥」条件；已送达未覆盖项多为「不是必须都加入」「不能替代具名联动」「持有不等于同站」「计量表可能遗漏单体效果」「招募位另算」一类限定句。7 项未送达中只有伺夜数值一项属「渐进披露本应覆盖而实际未完成」（该小节未登记关联对象），其余为机制小节未命中而模型未主动 read，仅 S02.5 一项属白名单内无承载文本（见结果 7 节）。S02 仅用 facts_search、S01 经文档范围 read 获得大量干员卡，两题的证据面形态差异明显。
