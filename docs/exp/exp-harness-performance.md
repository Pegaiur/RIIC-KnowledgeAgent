## 过程

### 范围与口径

本轮确认当前实现的执行、成本和检索性能，补跑一次真实 20 题样本并核查部分回答。不修改 harness、提示词、语料或评分规则，不把完成率当正确率，不以观察到的错误自动启动修复。

当前正式回答质量基线仍未指定；[答案核查规格](../../spec/rag-answer-baseline.md) 是核查口径。单次运行不能证明稳定性，原题直接检索的离线 recall 也不能代表 Agent 多轮改写查询后的证据覆盖。

### 已确认的当前配置

- Qwen3.7-Flash，Chat Completions 固定 auto，显式允许并行工具调用。
- BM25 / bigram，entityBoost=0，topK=5，每次检索最多 12,000 字符。
- 每题 5 点工具预算，总超时 300 秒，未调用工具直接作答时最多一次回馈。
- 默认 temperature 不传；本轮测量明确设为 0，thinking=off，maxTokens=4096。
- 当前题集 20 题、31 个白名单文档、749 个切块。
- 代码基点为 `b24af3ea5c0b50e42ab724b84599de26bb2a182d`；运行开始时工作区干净。运行按 `content.trim()` 计算的查询指令 SHA-256：`9388e3fe0b1d456e99afa40095568769e83357ba4f63bb4cdd475d8247703a00`。原文件未 trim 哈希不同，不混用两种口径。
- meta 在运行结束时采集源码状态，记录 `gitDirty=true`：运行期间仅新增本评估文档和 inbox 记录，harness、题集和知识库未改动。
