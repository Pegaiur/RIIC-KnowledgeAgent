核查口径：docs/spec/rag-answer-baseline.md（v6）的「必须覆盖」编号逐项判定，一条内列出的条件均须满足；「完整且有据」要求全部必答项满足且额外断言无冲突、未证实或待核验项（额外断言须核对自加例子、括注与额外名单）。三轮各由上下文隔离、未参与实现与其它轮次核查的执行者按同一提示词完成；事实比对以 base/guides 与 raw 为准。第 1 轮先出现一次初检（未按完整判定条剔除额外断言缺陷、判定覆盖面偏窄），随后按相同指令复检；下方初检汇总表保留的是该次复检提交的数字，本次追加审阅后不再将其视为已确认成绩。

费用与停止边界：三轮合计 ¥0.4887；未设达标线，未因结果修改语料、提示词、检索或预算。

2026-09-17 按用户要求追加复核：重算六轮运行计量、后三轮 read 来源与实际阅读范围，定向核对 F03、F07、F10、S02、S07 的答案和证据，提炼后续散文工作流。此次未调用模型、未修改语料或评分规格。该复核发现初检中的事实错误和判定不一致；未对前后六轮全部 432 个必答项重新评分，因此下列初检质量总数仅保留为过程记录，不能视为已确认成绩。

本次采用 spec v6 原有的「一项中的各条件均须满足」规则，不修改必答项。以下反例已足以否定初检总分的确认状态；只对定向发现下判断，不把局部修正冒充全量重评。

### 口径限制

- 运行与费用、记录数、调用计数、额度、字符总量取自各运行目录的 meta.json、records.jsonl、answers.md 与 trace.jsonl；read 来源已用互斥口径重算，答案语义仍需人工判断。
- 三轮由不同隔离执行者核查。第 1 轮同一份材料在初检与复检之间出现的差异（初检记 S02.5、G02.3 遗漏；复检记 F10.1 遗漏并另记 S02 额外断言）说明判定宽严与覆盖面仍有执行者差异，跨轮比较只具有「同一提示词下独立复核」的有限可比性。
- 额外断言的完整判定存在边界争议，例如第 2 轮对 S08 泛化的认定；此处按 spec 文字从紧处理，未使用隐含即覆盖的更宽口径。
- 本次仅完成计量复算与定向答案复核，未完成前后六轮统一全量重评；本次复核本身未经另一名审查者复核。历史 exp 与已登记快照不改写，本轮不指定新质量基线。
- 离线扩大试验的 50/50 目录可见与 12 条人工选读成功，仅说明指定问法的可达性；真实 Agent 会改写 query、选择阅读范围，不能把这两个离线结果当成自主送达或回答成功率。原 20 题已用于诊断和优化，后续还需未参与改写的新问题验证泛化。

## 结论

本轮是有价值的诊断试验，尚不能确认标题优化提高了总体证据送达或回答质量。原有质量总分存在漏判和跨轮不一致，已降为待统一重评的初检记录；不能用最好一轮的 18/20 或三轮平均值宣称收益，也不能凭这些总数宣称质量持平或退化。

已确认的价值有三项：一是实际 Agent 能通过整篇或父级补齐未命中小节，但入口可见不保证采用；二是 F07 的局部送达下降和 F03 同题不同阅读范围暴露出证据单元分散的问题；三是 F10、S07 显示送达之后仍有关系遗漏、推荐条件与技能触发混淆，标题优化的作用边界已经可见。三轮均无工具错误或预算拒绝，只能确认执行稳定，不能称导航路径一致。

后续散文优化宜按「对象明确的标题 → 规则与条件闭合的小节 → 首段关系及例外 → 精确事实引用」组织；哪些做法能改善自主取证与回答仍属待验证假设。候选工作流及分层对照设计见 docs/draft-prose-optimization-workflow.md，本次不实施语料或 harness 改动，不追加付费运行。

若需可比较的质量成绩，应以固定判定示例校准、隐藏版本的混排答案及同一套逐项规则统一重评，并对争议项另作复核；仅让同一执行者核查不能自动消除偏差。必要的判定短引文、语义来源和送达范围直接写入 exp 正文。本次仅终端复算，无新增试验附件或一次性文件；既有运行位于 bench-runs/，原执行任务的终端日志位于 dev-temp/work/title-optimization-3rounds/，其遗留清理由原产生任务按 scripts/INDEX.md 核对，不在本次读取过程中删除。本文已保存必要更正证据，不以这些临时原件承诺完整重放。
