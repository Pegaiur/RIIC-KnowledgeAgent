## 过程

### 目的与范围

渐进披露计划的第 6 步（gold 定位分离与 26 键迁移）已完成，`hitrate` 的定位目录与检索范围在装配上分离、金标分母不再随范围收缩删减，此前不可同口径重算的检索质量指标恢复可测。本轮据此兑现 exp-retrieval-hit-diff-migration「后续入口」中的推断，回答：在同一指标口径下，迁移后的 20 题 BM25 top-K 检索指标相对迁移前是升、降还是持平。

只做零模型费用的静态排名测量：不改代码、不改 gold/spec/题集/提示词、不调用模型、不设质量达标线，也不指定任何基线。

### 方法与口径

- 迁移后一侧：当前 HEAD `d588513`（分支 feature/index-and-tags），命令 `node dist/cli.js hitrate --topk 3,5,10`；gold 未改，仍为 20 题 69 键。定位目录＝manifest 19 份白名单（121 块）＋facts 声明的 11 份 raw 机械真源（621 块）；检索范围＝manifest 全部块。参数：分词器 bigram｜实体加权关｜maxContextChars 12000。
- 迁移前一侧：引用既有记录，不重跑、不复算。数值来自 exp-no-expand-read-section-glm-low「离线 hitrate」与 exp-expand-fulltext-glm-low「离线 hitrate」两轮（2026-09-15，两轮逐值一致，作为常量核对通过），其命令为 `--include-skill-tables 0`，参数同为 bigram／实体加权关／maxContextChars 12000。该侧的一次性脚本、命中集 JSON 与 worktree 检出已回收，本记录不承诺复算。
- 指标口径两侧相同：recall@K 键级按比例计、precision@K 块级、宏平均；金标在完整定位目录解析，被检索范围排除但真源存在的键计未命中且保留在 recall 分母。检索范围本身不同（145 块对 121 块），这正是本轮观测对象，不构成口径差异。
- 逐题对照只在 @5 可行：迁移前一侧留有逐题 @5 的 recall/precision，未保留逐题 @3／@10 与 nDCG。

### 3. @3 与 @10

只有宏平均可对照（迁移前一侧无逐题记录），因此无法定位变化到具体题目：@3 recall 47.7%→51.1%（+3.4pp）、precision 45.0%→48.3%；@10 recall 64.1%→66.7%（+2.6pp）、precision 19.0%→20.0%。这些差值可能来自少数题目的位次移动，本轮不作归因。

### 4. 与既有逐块核对的关系

exp-retrieval-hit-diff-migration 已逐块核对「迁移后 top10 掉出的块不含任何题目的自身 golden、且有 2 个锚点新进入 top10」，本轮从指标侧得到一致结果：@5 无任一题目下降，且 S02 出现上述新命中；未发现反例。

## 结论

- **支持**：在定位分离与 26 键迁移完成后，同口径下 @3／@5／@10 的宏平均 recall 与 precision 均不低于迁移前；@5 的全部变化就是 S02 的一处上升，即 exp-retrieval-hit-diff-migration 的方向性推断（@3／@5 与 @10 均不降）在本口径下成立，且此前无法判定的「是否有锚点新进 top5」得到回答：有 1 个。
- **不支持**：不能据此主张任何改善的质量含义。@3 与 @10 的上升无法定位到题目，也无 nDCG 对照；本轮无模型调用、无答案核查，排名变化不等于回答质量变化；位次置换的成因（范围收缩与同批语料文字改写）仍未拆分。单次静态测量、无重复采样、未经独立复核。
- **边界**：不设达标线、不改评分口径、不删减 gold 分母、不修改 gold/spec/代码；不登记 bench/results 快照、不修改质量基线表、不指定基线。两份已登记快照仍只适用迁移前来源与检索范围，本轮数值不与它们作同口径成绩对照。
- **后续入口**：第 7 步散文试点的第二时点（试点完成）仍需按 plan 第 7 步再跑一次 `hitrate --topk 3,5,10` 并记录 gold 旧→新映射；试点会改动小节标题与语料，届时同样只能作带口径说明的观察。真实模型观测按 plan 第 8 步，须另行登记并取得费用授权。
- **清理**：`hitrate` 只输出终端，未落盘；本轮无临时脚本、探针或中间产物，未新增入库产物。
- **复核状态**：本记录未经独立复核，不构成最终结论，也未指定为任何基线；迁移后一侧可复算（命令与配置已列明），迁移前一侧不可复算（既有记录的两轮数值引用）。
