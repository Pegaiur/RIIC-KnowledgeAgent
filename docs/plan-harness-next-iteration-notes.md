## 实现调整

### 2026-09-08 — 以 runner 捕获的 prompt 和回调接入观测
- **spec 原文**：首次模型调用前捕获实际 system prompt/schema；facts 仅在合法调用实际取得 store 后补记。
- **实际做法**：新增 `bench/src/inputs.ts` 负责显式白名单、原始/脱敏/最终文件哈希和源码状态；runner 在首个 provider 调用前写 pending `inputs.json`，把同一份 `systemPrompt` 传给 Agent，并通过 executor context 回调观测 facts store。
- **原因**：避免 Agent 再次读取变化中的指令文件，并避免为了记录 facts 而提前初始化全量门禁；观测回调异常不改变原工具语义。
- **后果**：新增 `AgentOptions`/`KnowledgeToolContext` 可选回调和 prompt 字段；meta 只导出 inputs schema/version/hash/maxTokens，旧快照字段仍可缺失。

### 2026-09-08 — 用开发期独立产物承载回放与留出题
- **spec 原文**：一次性回放、6 道新题和独立参考材料应保留用途，但不新增正式基准快照或污染运行时。
- **实际做法**：在 `dev-temp/work/harness-next-iteration/` 保存回放脚本/JSON/Markdown、留出题、参考要点和冻结清单；脚本只把问题文件交给检索测量，参考文件不被运行时读取。
- **原因**：按 scripts/INDEX 分离开发中间结果与正式 `bench/results`，并保留后续单变量实验的可复核输入。
- **后果**：A/B 原件没有改写；留出题若后续参与调参，必须改标开发集并另建最终验证题。

## 意外发现

### 2026-09-08 — Git 本地配置不可写
- **发现**：按仓库约定首次 Git 操作前尝试设置编码配置，但当前 checkout 的 `.git/config` 返回 Permission denied。
- **影响**：不改变 Git 元数据权限；后续只使用可读 Git 查询，最终报告该环境限制。

### 2026-09-08 — 历史指令正文在限定范围内无法恢复
- **发现**：A/B 的 meta/快照只保留 trim 后指纹；检查两个原件目录、快照、`dev-temp/work/independent-tools/` before/after 导出和相关 `knowledge/AGENTS.md` 后，未找到与 A/B 指纹精确匹配的正文。
- **影响**：报告明确列出检查范围和不可恢复结论，不以 LF/CRLF 或哈希推测历史语义；不阻塞输入记录、全量复核和离线诊断。

### 2026-09-08 — 固定来源与复核计数对齐
- **发现**：`knowledge/` 当前树与 spec 声明的 `b008f80c00c05097856921da946fe344bcaed600` 一致；spec v4 提供 72 个必答编号，A/B 各 20 份原答合计复核 144 项，额外断言检查 40/40。
- **影响**：报告维持 draft 待独立审定；待核验仅保留 S03 A 的来源映射，不修订 spec 或知识事实。

### 2026-09-08 — 留出题非空送达不等于参考点覆盖
- **发现**：6 道冻结留出题均有非空 `rag_search` 结果，但与冻结参考要点逐点对照后，20 个拆分点为已覆盖 15、部分覆盖 3、未覆盖 1、未核实 1；H-M01、H-C02、H-G02 的要点送达较完整，缺口集中在 H-M02、H-C01 和 H-G01 的边界条件。
- **影响**：详细来源和送达片段记录在 `dev-temp/work/harness-next-iteration/holdout-retrieval.md`；不能把 6/6 非空写成参考点已覆盖。当前不修改冻结题目、参考材料、manifest 或检索实现，ROI 只支持针对实际缺口做离线候选验证；若调参，另建开发集并保留六题作最终验证。
