## 意外发现
> 实施中发现的 spec 未覆盖的依赖、边界或风险

- `splitChunks` 仅消费 `##`/`###`，H1 只作为 `anchor`；因此自然标题必须使用 H2，H1 不能替代块标题。
- 旧 base 中“技能维度数值”注释本身会把具体技能个例和过时的术语带入玩家侧扫描；已改为只指向 references，避免与技能真源和术语检查冲突。
- raw 案例复核结果：16/4/4 中 A/B 为 20 小时工作、4 小时休息，C 为 8/16；若 8/8/4/4 只是前者拆分，合计不变；按同样的三组轮换解释，12/12/12 为 24/12，12/6/6 为两组 18/6 与一组 12/12，24/24/24 为 48/24。上述算术不证明具体阵容、容量或产出，故全部标记为“仅作例子”并排除白名单。
