# 开发临时区精简与分支收尾计划

> 创建日期：2026-09-06
> 状态：施工中
> 工作分支：`feature/temp-cleanup`

## 目标

按「如无必要勿增实体」收敛临时区：临时脚本与结果共置，分支触发收尾，默认搜索排除临时物，纯评估不制造新文件。复用现有工具和清单，不增加分类台账或状态协议。

## 非目标

不新增目录分类体系、注册表、分支归属映射、定时器、保留天数、导入重写器或审批机制。不修改 dist 的构建职责，不把临时文件转存系统临时目录以掩盖积累。不执行生产目录批量迁移、真实删除、付费请求、合并或推送；旧存量本次只给出具体去留建议和终端预览。

## 架构分析

dev-temp 已被 Git 忽略，普通 rg 搜索会排除；噪音源于绕过忽略规则的全仓遍历和散落产物。现有 runs 有 verify 等真实消费者；work 可复用为任务容器；cache 的辅助接口暂无业务消费者。scratch 的独立目录及 new/promote 主要由自身维护，临时脚本实际多与实验结果散落在 dev-temp。

## 实施方案

### 1. 只保留必要落位

- `scripts/tasks/`、`scripts/lib/`：正式维护工具及已有共享代码。
- `dev-temp/work/<任务>/`：临时脚本、输入、结果及需交接的产物共置；目录名人工确定，不编码分支身份。不另嵌一层 scripts/results 子目录作为强制模板。
- `dev-temp/runs/<工具>/<run-id>/`：保留正式工具自动产生的运行记录及现有结束产物约定。
- `dist/`：仍为构建输出，沿用构建流程。

新临时产物不得散放 dev-temp 根目录。一次性计算、查询和评估优先直接终端输出；需要继续执行或交接才落盘。work 不再定位为人工永久保存区；长期资产进入既有正式目录。保留现有已忽略路径供旧文件存续，不因取消规范就取消 Git 忽略而暴露历史产物。

### 2. 删除无消费者的抽象

核对实际调用后移除 cache 专用目录接口及文档推荐；普通实验数据随任务存放。取消 scratch 临时区及 `tooling new/promote` 命令、只服务它们的模板/辅助代码和测试。正式 `tooling run/list` 及其消费者保留；共享函数有其他调用时不得一并删掉。

临时脚本需要正式化时，作为普通代码变更放入 scripts/tasks，人工修正相对导入并做匹配验证，不构建自动提升替代系统。不移动、删除现存 scratch 文件。更新活跃文档与帮助；冻结历史文档不批量回写。不为退役的本地开发便捷命令维持兼容别名或迁移状态文件。

### 3. 预览默认不落盘

保留现有 `tmp clean --manifest <path> [--apply]` 和清单生成入口。在同一 clean 入口支持 `tmp clean --reason <理由> <路径...>` 或 `--snapshot <共享快照> <路径...>` 直接预览：在内存生成候选清单，复用现有条目评估与输出，不写清单文件，不自动 apply；直接路径与 --apply 组合应拒绝并提示既有持久清单用法。不新增命令文件或复制保护逻辑。评估器的 manifestPath 显式可选，只有存在时才检查清单自身，输出标为内存预览，不伪造文件路径或将 undefined 传给路径解析。

确实准备后续执行才通过既有 manifest 入口保存一份清单，推荐位于对应 work 任务目录，但必须放在所有候选目标之外；清理整个任务目录时放在其外，避免写清单本身改变目标指纹。清单执行成功自删除、部分失败保留重试，保持现有行为；放弃执行时删除清单本身即可，不触碰目标。预览、计划和统计不为自身生成永久日志。

### 4. 分支收尾与搜索规则

将权威使用规则写入现有 scripts/INDEX.md，AGENTS.md 仅保留简短路由和默认搜索约定，release-workflow 仅引用收尾时机；同步实际源码注释，不维护多份同义规范。

分支合并或放弃时处理本轮明确选择的产物：正式资产入库、继续使用的交接、其余清理。临时物归属按任务目录和实际用途核对，不推测整个目录属于当前分支，不要求其他任务同时结束。正式基准原件继续遵循共享条件；已确认无用途的一次性产物可任务结束即清理，无需等合并。保留理由写既有笔记，不增加登记文件或每任务状态 JSON。

默认搜索限定相关模块并遵守 .gitignore；确需查看忽略区时指定具体路径。避免全仓 --no-ignore/-uuu 或通用递归遍历；查看隐藏配置时也限定配置目录，不扫整个 .git。

### 5. 旧存量与验证

核对 dev-temp 根现有脚本、目录及现有清单：按任务组给出提升、待交接、可舍弃或备份待核对结论，仅终端汇报，不新增分类文档/迁移清单。不得为目录整齐强制搬移所有旧文件，尤其不能移动后让现有清单路径或指纹失效。现有 `dev-temp/cleanup-temp-cleanup-closeout.json` 若仍准备执行则保留并说明；不要因禁止新根文件而删除待执行清单。

在已有测试文件中验证直接预览不写文件不改目标、参数组合拒绝、现有清单执行及失败保留、仍有消费者的 run/list；确认 new/promote 退役后的帮助和错误行为一致。无需测试自然语言规范或新增测试框架。

运行 typecheck、test、build 后 validate、doc-check，验收项据实勾选后跑统一合并门禁。创建计划阶段保留未勾选 D1，不能伪造实施完成。本地命令简化不引入新模块、依赖或构建策略；若发现超出上述本地便捷入口的真实公共契约消费者，先记录并限定范围，不擅自扩展架构迁移。

## 验收清单

- [x] work/runs/正式工具职责及分支收尾、搜索规则一致，cache/scratch 的无消费者接口退役，无新增实体体系。
- [x] 直接路径清理预览复用既有校验且无文件写入，真实 apply 仍走持久清单；成功自删及失败保留不回退。
- [x] 旧存量按任务组给出具体去留建议，未生成新分类台账、未搬移或删除生产产物及待执行清单。
- [x] typecheck、test、build 后 validate、doc-check 及统一合并门禁通过，未付费跑测或自动合并推送。
